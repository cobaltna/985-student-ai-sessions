# 思考小窗 · ZCode

ZCode 的思维链（reasoning）是英文的。这枚悬浮小球把它翻成中文。

原理：ZCode 每完成一次 API 往返，就把该轮思考追加写入
`~/.zcode/cli/rollout/model-io-session_*.jsonl` 的 `response.reasoningText` 字段。
小窗用目录变更通知（ReadDirectoryChangesW）实时感知这个目录，逐轮翻译新出现的思考。
纯外部读取，不改动 ZCode 的任何文件和配置，不注入任何上下文。

## 用法

- **小球**：圆形、无矩形底框（窗口用透明抠色只保留圆），常驻屏幕右侧；
  点击展开翻译窗（并自动补上错过的思考），拖动可挪位置；「×」只收起窗口回小球，
  **彻底退出走小球右键菜单 →「退出小窗」**。
- **标签页**：窗口顶部是「思考流翻译 | 划词翻译」标签栏，点标签切换内容区；
  激活标签亮色加下划线。点球展开默认落在思考流页；复制英文后自动切到划词页。
  暂停按钮只在思考流页显示；最后停留的标签会记住。
- **改大小**：无边框窗口，拖**左边 / 右边 / 底边 / 右下角**都能调整尺寸（右下角有缩放把柄），尺寸和位置会记住。
- **思考流翻译**：多会话各自跟踪、并行翻译，第二会话起每轮带会话短标记区分；
  新对话的第一轮也会翻（≤2MB 回看全文件，续开旧对话取尾部 8000 字）。
  - **阅读位置不会自动跳**：只有当视口停在底部时才自动跟随；向上翻看后，新译文照常追加在下方，视线不动。滚回底部（或按 End）即恢复跟随。
  - 点「思考流翻译」标签 → 回溯翻译当前会话最近的思考（已翻过的去重）。
  - 点「暂停 / 继续」→ 随时中断；暂停期间新思考跳过，缺口用回溯补。
  - 收起小球 = 自动暂停（零翻译开销）；再展开时自动回溯补上缺口。
- **划词翻译**：展开状态下复制英文（Ctrl+C），约 1 秒出中文；收起时不监控。
- 右键文本区可清空；Esc 收起；关闭时记住窗口/小球位置。

## 随 ZCode 启停

- 计划任务 `ZCodeCotPeek` 每分钟检查：ZCode 在运行且小窗没跑 → 自动拉起
  （所以打开 ZCode 后约 1 分钟内小球出现）。
- ZCode 退出 → 小窗**即时**跟随退出：对 ZCode 根进程句柄做 `WaitForSingleObject`，
  进程一结束立刻返回（实测 ~60ms），期间零唤醒零 CPU。
- 小球右键「退出小窗」→ 本次 ZCode 会话内不再自动拉起；重启 ZCode 后恢复自动。
- 手动启动：双击 `start-cot-peek.bat`（重复启动自动拒绝）。

## 进程检测（为什么不再有子进程）

ZCode 是 Electron，同时有二三十个同名 `ZCode.exe`；只有「父进程不是 ZCode.exe」
的那个是根进程，用它做会话签名与退出等待。进程枚举全在进程内完成，三级降级：

| 通道 | 单次耗时 | 说明 |
|---|---|---|
| `NtQuerySystemInformation` | 3.6 ms | 首选 |
| `CreateToolhelp32Snapshot` | 6.2 ms | 系统调用被拒时兜底 |
| `tasklist` 子进程 | 393 ms | 最后兜底（正常不会走到） |

对比旧版「每 5 秒起一个 tasklist」：每小时 720 个子进程 → 现在 0 个。

## 翻译质量与接口

- **主通道：火山翻译免密 web 接口**（translate.volcengine.com，0.2~0.8 秒/次，
  单请求上限约 4000 字，无需 key；瞬态 500 自动重试一次）。
- 次选 cn.bing.com（约 900 字/请求），最后兜底 MyMemory；都失败显示英文原文并标红。
- **思考按 ~1000 字段落切分、3 线程并发翻译，每段完成即上屏**（实测火山单段
  0.3~1 秒；两三万字的大轮次也能几秒到十几秒内陆续出完）。
- 代码围栏、无字母行、中文行原样保留；代码块/行内代码/URL/文件路径/常见术语
  （MCP/API/JSON/Token…）先占位 `[[n]]` 再翻，翻完还原。
- 状态机：入队未完成=可重试；中断的段会被释放，下次回溯会补翻。

## 性能

- 收起时：只等目录通知与进程句柄，零轮询、零翻译、零剪贴板读取。
- 思考流：目录变更通知即时唤醒（实测写入 → 出译文 0.05~0.5 秒），
  5 秒一次全扫兜底防漏事件；空闲不唤醒。
- 展开时：300ms 剪贴板序号检查（收起后停止）。
- 译文缓存 500 条；文本区超 8 万字自动截尾。
- 官方实测：空闲 20 秒平均 CPU 占用 0.0% 单核。

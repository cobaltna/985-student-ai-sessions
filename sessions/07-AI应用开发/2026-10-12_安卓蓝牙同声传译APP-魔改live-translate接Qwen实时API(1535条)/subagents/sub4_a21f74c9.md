# True Simultaneous (Streaming) English→Chinese Speech Translation — Open-Source Landscape

Date context: 2026-10-12. All dates below are as observed from repos/API today. "Releases" referenced in 2026 are what the sources actually show.

## Bottom line up front

- **Only one released single model does EN→Mandarin simultaneous speech+text with a shipped checkpoint: Meta SeamlessStreaming** (`cmn` is in the released `seamless_streaming_unity` unit list). But weights are **CC-BY-NC-4.0 (non-commercial)**, Linux-only research code.
- **The practical open EN→ZH route is a cascade.** The most turnkey, permissively licensed one is **WhisperLiveKit + NLLW** (Apache-2.0, actively maintained, built-in zh translation over WebSocket).
- **Standout research release with an actual EN→ZH simultaneous checkpoint: InfiniSST** (MIT, 8B, released en-zh `.bin`).
- **Hibiki is French→English only** — not usable for EN→ZH.
- **Qwen3-Omni / Voxtral / Qwen3-ASR are not true EN→ZH simultaneous translators**: Omni is turn-based streaming (not mid-utterance), Voxtral Realtime streams *transcription* not translation, Qwen3-ASR is transcription-only.

## 1. Meta SeamlessStreaming / SeamlessM4T v2

- **EN→ZH: YES, released checkpoint supports it.** Streaming docs: ASR 96 langs; simultaneous translation 101 source speech langs; **96 target langs for TEXT output; 36 target langs for SPEECH output**. So EN→ZH (Mandarin, Han simplified) works for both text and speech with shipped weights.
- **Streaming is real:** EMMA monotonic-decoder + streaming UnitY2 (`seamless_streaming_unity.pt`, `seamless_streaming_monotonic_decoder.pt`), 2.5B params, SimulEval-based policy. **API: research/eval code only** (`streaming_evaluate` CLI + agent pipeline), no production server.

## Recommendation for a solo developer

**Most realistic: a cascade, not a single end-to-end model.**

1. **Fastest to working EN→ZH text:** run **WhisperLiveKit** (`wlk --target-language zh`) — Apache-2.0, actively maintained, WebSocket + OpenAI-compatible API, streaming partials, NLLB-based zh translation, GPU or CPU profiles. This is the only permissive, turnkey, real-EN→ZH-streaming-text option.
2. **Higher translation quality, still permissive:** **SimulStreaming (MIT)** with Whisper large-v3 + **EuroLLM-9B (Apache-2.0)**, `--tgt-lan zh-sim`. Costs 1–2 GPUs. Text-out only.
3. **Add speech-out:** cascaded TTS — **Kokoro-82M (Apache-2.0, Mandarin)** or sherpa-onnx zh TTS. No released project ships a clean, permissive EN→ZH *text+speech simultaneous* end-to-end stack; you assemble it.
4. **If you accept non-commercial weights and Linux:** **SeamlessStreaming** is the only single-model EN→ZH simultaneous text+speech with a shipped checkpoint — but CC-BY-NC-4.0, research code, and Linux-only tooling.
5. **If you want a pure-offline appliance reference:** study **RTranslator (Apache-2.0)** or **hayamimi (MIT)** rather than reinventing the pipeline.

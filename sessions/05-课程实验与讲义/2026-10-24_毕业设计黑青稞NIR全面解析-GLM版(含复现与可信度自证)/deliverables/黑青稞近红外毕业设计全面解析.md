## 1. 题目讲解

### 1.1 黑青稞是什么，为什么要测这三个指标

青稞（hulless barley，学名裸大麦 *Hordeum vulgare* var. *nudum*）是青藏高原对裸大麦的叫法：穗上籽粒成熟后颖壳自然脱落，裸粒收获。它是藏区主粮（糌粑原料），也是青稞酒、青稞面的原料。"黑青稞"指种皮富含花青素而呈黑紫色的一类品种，是特色杂粮。

三个指标各自的意义：

| 指标 | 决定什么 | 文献报道的典型范围 |
|---|---|---|
| 水分 | 储藏安全（一般要求 ≤13% 才不易霉变）、加工粉碎性能 | 约 7%~13% |
| 淀粉（总淀粉） | 糌粑/酿酒精的得率，直链/支链比例影响口感 | 约 48%~79%（甘孜 31 个品种实测） |
| 蛋白质 | 营养价值、饲料价值、面制品加工性 | 约 6%~21%；黑青稞品种实测 12.19%~14.07% |

来源见第 5 章文献 [6][7]。这三个量合在一起，基本刻画了"这批黑青稞能干什么用、值多少钱"。

### 1.2 传统方法的问题，近红外的机会

现行测定方法都是"破坏性化学实验"：

- 水分：烘箱 105 ℃ 烘至恒重（GB 5009.3 直接干燥法）——数小时；
- 蛋白质：凯氏定氮，浓硫酸消解+蒸馏滴定（GB 5009.5）——半天起步，用强酸强碱；
- 淀粉：酶水解后测葡萄糖（GB 5009.9）——流程最长，试剂最贵。

三个指标都测完，一个样品要一整天，样品也被磨碎销毁了。收粮、育种中间世代筛选、生产线在线质控都等不起这个速度。

近红外（NIR）的思路完全不同：**不再分离提纯待测成分，而是让光"穿过/扫过"整粒籽粒，从整条光谱里反推含量**。一次扫描 1 分钟内出三个指标，不破坏样品，不消耗试剂。代价是：光谱与含量之间不再是简单的物理定律，需要用统计学习（化学计量学）从一批"光谱+化学值"已知的样本里学出一个回归模型。这个"学"的过程，就是你的全部毕业设计工作。

### 1.3 近红外为什么能测出成分（物理原理，大白话版）

分子的原子时刻在振动，像用弹簧连接的小球。不同化学键（O–H、C–H、N–H）的"弹簧刚度"和"小球质量"不同，固有振动频率就不同。近红外光（800~2500 nm）的频率恰好能让这些键发生振动跃迁，光能量被吸收，特定波长处透射/反射光变弱——这就是吸收峰。

红外光谱分两段：

```
中红外 MIR (2500~25000 nm): 基频吸收 —— 峰形尖锐、指纹区可鉴定"是什么物质"
近红外 NIR (800~2500 nm):   倍频+合频 —— 峰比基频弱 10~100 倍、峰宽、严重重叠
```

NIR 峰弱而宽，"看图谱鉴定物质"很难，但"测混合物里某成分的含量"反而合适：峰宽意味着峰面积与含量近似线性相关。三个目标成分的指纹（文献常用归属，教材级共识，写论文时可引 Williams & Norris《Near-Infrared Technology in the Agricultural and Food Industries》）：

```
水  分 O–H : 1450 nm(一级倍频) 、 1940 nm(合频, 全谱最强峰)
蛋白质 N–H : 2050 nm 、 2180 nm(酰胺键合频)
淀  粉 C–H/O–H : 2100 nm 、 2270 nm 、 2324 nm
```

把这六个数记住——后面复现中 CARS 筛出来的波长会一个个落回这些位置，那是整条技术路线成立的物理根基。

还有一个对"黑青稞"特别要紧的现象：**整粒籽粒是固体颗粒，光是"弹"回来的（漫反射）**。光在颗粒间不断折射反射才回到探测器，颗粒大小、装样松紧、表面颜色的差异会整体抬高或压低整条光谱（散射），黑青稞种皮颜色深、色素吸收强，散射和基线干扰比浅色谷物更明显。这就是任务书难点(1)的来源，也是"预处理"一整章存在的原因。

### 1.4 化学计量学：为什么需要一整套数学

一条光谱 700 个波长点。你有 100 个样品。想用 700 个自变量去拟合 100 个方程——方程比未知数少得多，普通最小二乘有无穷多组解（矩阵不可逆，专业说法叫"严重共线性"：相邻波长高度相关）。而且光谱里混着散射、基线、噪声，它们和含量无关却数值很大。

化学计量学就是为此发明的一揽子方案，对应关系：

```
问题                          →  工具
光谱里有散射/基线/噪声         →  预处理 (SG平滑/SNV/MSC/求导)
700个共线变量 vs 几十个样本    →  PLS 回归 (先把700个变量压缩成几个"潜变量")
担心选进校正集的样本偏科       →  SPXY 划分 (保证校正集覆盖全范围)
想砍掉无关波长、只留特征峰     →  CARS 变量筛选
想知道模型到底好不好           →  Rc/Rp/RMSEC/RMSEP/RPD
```

### 1.5 三个"应解决的问题"与三个"难点"逐条翻译

**问题(1) 有效采集与预处理优选** → 我买的仪器怎么设参数（扫描次数、分辨率、装样方式）？采回来的光谱有散射和噪声，7 种预处理组合哪个对黑青稞有效？——用数据说话：同一批数据跑 7 种预处理，谁建模误差小谁赢。

**问题(2) 特征变量筛选与定量模型** → 700 个波长里很多与成分无关，用 CARS 把"对预测该成分贡献大的波长"筛出来，再用精简后的光谱建 PLS 模型。好处：模型更稳、更可解释（筛出的波长应落在 1.3 节那六个特征带上）、未来可做窄波段便携仪器。

**问题(3) 稳定性与泛化验证** → 模型在"没见过的样品"上还行不行？用独立预测集考试、用多个随机划分看波动（本复现做了 5 种子重复）、有条件再留一批外部样本（另一年/另一产地）最终验证。

**难点(1) 深色种皮+组分复杂** → 上文散射问题，靠散射校正预处理+导数解决。
**难点(2) 三组分波段重叠** → 2050/2100/2180 nm 挤在一起，肉眼无法区分。CARS 的价值正在此：复现结果里蛋白模型选中 2046/2190 nm、淀粉模型选中 2130/2282 nm——各回各家。
**难点(3) 样本量与代表性** → 模型是从样本里"学"出来的，样本必须覆盖目标产区、品种、年份的真实变异。经验下限：80~150 个样本，含量梯度尽量拉开；划分用 SPXY 保证校正集覆盖两端。

## 2. 理论速成

### 2.1 光谱是怎么变成一个数字矩阵的

仪器每个波长测一次"光被吸收了多少"。反射式仪器实际记录反射率 R，再取对数变成**吸光度 A = log₁₀(1/R)**——取对数是为了让 A 与浓度近似成正比（比尔-朗伯定律的推广形式）。最终每个样品得到一行 700 个数，n 个样品摞成 n×700 矩阵 X。

```
波长 →   1100 1102 1104 ............ 2498   (700列)
样品1  [ 0.31 0.31 0.32 ......      0.28 ]
样品2  [ 0.35 0.35 0.36 ......      0.31 ]   ← 每行一条光谱
 ...
样品n  [ 0.29 0.30 0.30 ......      0.26 ]
```

### 2.2 预处理四件套

先建立一个直觉：一条实测光谱 = **化学信号(想要) + 基线漂移(不要) + 乘性散射(不要) + 随机噪声(不要)**。预处理就是分层剥掉不要的部分。

**SG 平滑（Savitzky-Golay）**——治噪声。在滑动窗口（如 11 个点）内拟合一条二次曲线，用曲线中点代替原数据点。相当于"局部多项式回归降噪"。窗口太大峰会一起被抹平，太小噪点残留，常用 7~15（本复现取 11）。

**SNV（标准正态变换）**——治乘性散射。每条光谱自己减自己的均值、除自己的标准差。物理含义：把"这条光谱整体偏亮/偏暗"的散射差异归一掉，只留形状信息。

**MSC（多元散射校正）**——同样治散射，思路是"对齐参考"。以校正集平均光谱为参考线，把每条光谱对参考做线性回归 x ≈ a·ref + b，再逆变换 (x−b)/a。a 就是该样品的散射强度因子。SNV 与 MSC 效果通常接近，SNV 不需要参考更简单。注意：参考光谱只能用校正集算，否则预测集信息会泄露进模型。

**一阶导数 D1**——治基线+重叠峰。对光谱求导：常数的导数是 0，缓慢倾斜的基线求导后接近 0，吸收峰变成"峰-谷"对，重叠的宽峰被拉开分辨。实现上用 SG 求导（窗口内多项式的解析导数），别用相邻点差分（会放大噪声）。

组合原则：**先散射校正/平滑，再求导**（SNV+D1、MSC+D1 是文献最常用组合）。但组合不是越多越好——见 4.3/4.4 节，真实数据上水分最优是"原始光谱"，仿真数据上 SNV 反而伤害淀粉模型。预处理必须逐一对比，让 RMSEP 说话。

### 2.3 SPXY 样本划分（Galvão et al., 2005）

把 n 个样本分成校正集（训练）和预测集（考试）。随机分的风险：运气不好时最高含量的几个样本全进了预测集，模型没"学过"高分段，考试必挂。

SPXY（Sample set Partitioning based on joint X–Y distances）是贪心算法：

1. 算每对样本的**光谱距离**（归一化到 0~1）和**成分距离**（同样归一化），相加得联合距离 D——既看光谱差异又看含量差异；
2. 距离最远的一对样本（含量最低与最高附近）先进校正集；
3. 每轮把"离已选样本最近距离最远"的样本纳入——即每次挑对覆盖范围贡献最大的点；
4. 直到校正集达到 3:1 的配额（如 80 样本 → 60 校正 + 20 预测；180 样本 → 135+45）。

效果见 `results/*/fig3_spxy_*.png`：预测集样本均匀散布在校正集覆盖的含量范围内，两端极值都在校正集里。

### 2.4 PLS 回归（偏最小二乘）

普通最小二乘失败的根源：700 个自变量、60 个样本、相邻波长相关系数 0.999。PLS 的思路是**先压缩再回归**：

1. 从 X 中找一个线性组合 t₁ = X·w₁（w₁ 是权重向量），使 t₁ 既解释 X 的方差、又与 y 的协方差最大——t₁ 叫第一潜变量（latent variable），本质是"最能代表光谱-含量关系的复合波段指数"；
2. 把 t₁ 解释掉的信息从 X、y 中扣除（残差化）；
3. 在残差上重复，得 t₂、t₃……各潜变量相互正交；
4. 用 3~10 个潜变量对 y 回归，代替 700 个原始波长。

潜变量个数是 PLS 唯一要调的超参数：太少欠拟合，太多过拟合。用 10 折交叉验证选（本复现 `chemlib.select_ncomp_cv`，取 RMSECV 最小的个数）。PLS 顺带不怕预处理后的量纲问题（内部已中心化）。

### 2.5 CARS 变量筛选（Li et al., 2009）

700 个波长里，与目标成分真正相关的只有特征峰附近几十个点；其余是无信息变量，白占维度还引入噪声。CARS（Competitive Adaptive Reweighted Sampling）借达尔文"适者生存"做筛选：

1. **蒙特卡洛抽样**：随机抽 80% 校正样本建模，回归系数 |b| 大的波长 = 对预测贡献大 = "适应度高"；
2. **指数衰减函数 EDF**：每轮允许存活的变量数从 700 指数衰减到 2——前 25 轮粗选（直接淘汰弱者），后 25 轮精选；
3. **自适应重加权采样 ARS**：精选阶段按 |b| 为权重做不放回轮盘赌抽样，强者概率大，但弱者也有翻身机会（保留组合多样性）；
4. 每轮用未抽中的 20% 样本算 RMSECV，**取误差最低（本复现默认：最低误差一倍标准误内变量最少的轮，1-SE 规则）的那组变量**进最终模型。

为什么用 1-SE 规则而不是绝对最小：每轮 RMSECV 只用约 20% 样本估计，抽样噪声不小；统计学标准做法（lasso 同款）是在"统计上同样好"的轮里选最简子集。实测（qingke 蛋白）：绝对最小选 434 个变量 Rp=0.9968，1-SE 选 31 个 Rp=0.9965——变量砍掉 93%，精度几乎不掉。

### 2.6 评价指标与"多少分算好"

设校正集拟合值 ŷ_c、预测集预测值 ŷ_p：

```
Rc  = corr(y_cal, ŷ_c)      校正集相关系数   → 模型对"学过的数据"拟合多好
Rp  = corr(y_pred, ŷ_p)     预测集相关系数   → 模型对"没见过的数据"预测多好(更重要)
RMSEC = √mean(y_cal−ŷ_c)²   校正集均方根误差(单位=%)
RMSEP = √mean(y_pred−ŷ_p)²  预测集均方根误差 → "平均猜偏了百分之几"
RPD  = SD(y_pred) / RMSEP   预测集标准差是误差的几倍 → 消除含量范围影响, 跨研究可比
RPIQ = IQR(y_pred) / RMSEP  用四分位距代替SD, 抗极端值
```

RPD 判据（Williams 系列，被谷物 NIR 文献普遍采用）：

| RPD | 解读 |
|---|---|
| < 2 | 模型不可用（误差和样本自然波动一样大） |
| 2 ~ 3 | 可用于初步筛查 |
| 3 ~ 5 | 良好，定量可用 |
| > 5 | 优秀 |

一个必须警惕的现象：**Rc 高、Rp 低 = 过拟合**（模型把训练数据的噪声也当规律背下来了）。RMSEC 与 RMSEP 差距大、或 CARS 后变量数不减反增，都要检查。另外 RPD 依赖预测集的含量范围——范围窄的数据集 RPD 天然低（corn 水分 SD 只有 0.38%），比较模型时说明清楚，必要时补报 RPIQ。

## 3. 任务书八步逐条精讲

> 每一步给出：目标 → 具体做法（参数级）→ 常见坑 → 自查清单。标 ★ 的是已经在本复现中真实跑通、可直接用代码验证的部分。

### 3.1 第 1 步：文献调研 ★

**目标**：搞清楚三件事——别人在谷物/大麦/青稞 NIR 上做到什么水平；技术路线有哪几条岔路；你的工作量预期在哪。

**做法**：
- 中文库（知网/万方）检索词组合：`青稞 AND 近红外`、`大麦 近红外 蛋白`、`CARS 偏最小二乘 光谱`、`SPXY 样本划分`；
- 外文库（Web of Science / PubMed / Google Scholar）：`hulless barley OR highland barley AND near infrared`、`competitive adaptive reweighted sampling`、`NIR grain protein starch calibration`；
- 精读 5~8 篇：1 篇青稞/大麦 NIR 全流程（首选 Li et al. 2025，见第 5 章 [1]，五个参数+六种预处理+CARS/SPA，和你题目几乎同构）、1 篇预处理系统比较（Heil 2021 [5]）、CARS 原文 [3]、SPXY 原文 [4]、1~2 篇谷物 NIR 综述。

**常见坑**：只看中文文献会漏掉方法源头（CARS/SPXY 都是英文原文）；只看方法文献不看谷物应用文献会不知道合理指标范围。

**自查**：能不查资料说出"谷物水分 Rp 通常 >0.98、蛋白 0.9~0.99、淀粉 0.85~0.95，淀粉最难"——这就是你论文结果的合理预期。

### 3.2 第 2 步：样本制备（参考值测定）

**目标**：拿到每个样品三个成分的"真值"。模型永远不可能比真值更准——这是全项目质量的天花板。

**采样设计**：
- 维度：产区（如西藏/青海/甘肃或省内 3~5 个县）× 品种（含 2~3 个黑青稞主栽品种）× 收获期/年份，尽预算拉大含量梯度；
- 数量：80~150 个**独立样本**（一个地块混收算一个样本；同一袋分装多份不是独立样本）；
- 每个样本量 ≥200 g：一份磨粉测化学值，一份整粒测光谱（或同一份先测光谱后磨粉，推荐后者，绝对同源）；
- 编号建档：产地、品种、收获日期、储存条件全部入表——论文表 1 和后面异常样本溯源都靠它。

**参考值测定（国标方法，写进论文实验部分）**：

| 成分 | 国标 | 方法要点 | 注意 |
|---|---|---|---|
| 水分 | GB 5009.3-2016 | 第一法 直接干燥法，101~105 ℃烘至恒重 | 样品磨粉后立即测，避免吸潮 |
| 蛋白质 | GB 5009.5 系列 | 第一法 凯氏定氮（或燃烧法） | 换算系数按标准附录表选（麦类常用 5.70，务必按现行版本标准核对） |
| 淀粉 | GB 5009.9-2016 | 酶水解法（淀粉酶水解→测葡萄糖） | 与脂肪/蛋白测定配合，注意脱脂处理 |

每个样品做双平行，相对偏差超限（如 >5%）重测。记录每一次称量与结果，论文附精密度数据。
**国标会更新**（GB 5009.5 已有新版发布）：开题时到"食品安全国家标准数据检索平台"（sppt.cfsa.net.cn）确认现行版本号再写进论文。

**常见坑**：①先磨粉测化学值、另取一份测光谱——两份不是同一个物质状态；②化学值量程太窄（比如水分全在 9~11%）→ RPD 天然低，模型再好也"不好看"，采样时就要刻意拉梯度（不同收获后干燥程度、不同储存时间）。

**自查**：三成分各自的范围、SD、分布直方图已画出；含量跨度对得起采样设计。

### 3.3 第 3 步：光谱采集

**目标**：把测量误差压到小于化学信息，否则后面全白干。

**仪器与参数**（论文可写的典型配置，按实验室实际改）：

```
仪器: 傅里叶变换近红外光谱仪(FT-NIR), 带积分球漫反射附件
     常见型号举例: Thermo Antaris II / Bruker MPA / 波长范围相当的分光光度型仪器
光谱范围: 10000~4000 cm⁻¹ (即 1000~2500 nm)
分辨率:   8 cm⁻¹
扫描次数: 64 次平均成一条(压制随机噪声)
样品杯:   旋转杯(让光扫过籽粒更多位置, 抵消籽粒排布不均)
背景:     每测 5~10 个样品重测一次背景(金板/内置参考)
环境:     室温 25±2 ℃, 样品提前 24 h 恒温(温度影响水的吸收峰形)
重复:     每个样品装样 3 次、每次扫描 1 条, 3 条平均为该样本光谱
```

**装样规范**：籽粒铺满杯底、厚度 ≥2 cm（保证光不会从底部漏过）、每次装样尽量同样紧实度、表面刮平。

**常见坑**：①样品温度不一致——早晨测的凉、下午测的热，水峰漂移被当成化学差异；②背景长时间不更新，仪器漂移进入光谱；③只扫一条不留重复，无法评估测量重复性（论文答辩必问）。

**自查**：同一样品 3 条重复光谱的吸光度极差 < 0.005 A 量级；全部光谱无平头（饱和）、无断崖。

### 3.4 第 4 步：光谱预处理优选 ★

**目标**：对每个成分找出使预测误差最小的预处理。

**做法**：固定同一 SPXY 划分和 PLS 流程，只换预处理跑 7 种：原始、SG、D1、SNV、MSC、SNV+D1、MSC+D1，比较预测集 RMSEP/RPD。判据唯一：**RMSEP 最小者胜出**，并列时选更简单的（奥卡姆剃刀）。

代码一行不用写，`02_run_pipeline.py` 已把 7×3 全部跑完（见 4.3/4.4 节表格）。

**常见坑**：①把预处理当玄学堆叠（SNV+MSC+D1+D2……），每一步都可能毁掉化学信息的绝对幅度——本复现仿真集上 SNV 让淀粉 Rp 从 0.86 掉到 0.47，是活例子；②用全数据集算 MSC 参考光谱（信息泄露，正确做法只用校正集）；③导数窗口不交代（论文必须写明 SG 窗口和阶数）。

**自查**：每种预处理的 RMSEP 表在论文里完整呈现（不是只报最优）；最优选择的理由能一句话讲清。

### 3.5 第 5 步：SPXY 样本集划分 ★

**目标**：3:1（或 4:1，文献两者都常见，80~180 样本量级用 3:1）划分，保证代表性。

**做法**：`chemlib.spxy_split(X, y, ratio_cal=0.75)`。三个成分各用各自的 y 做 SPXY（成分梯度不同，最优划分不同），论文里说明即可。

**常见坑**：①随机划分（`train_test_split`）不打招呼就用——含量极值样本落进预测集就是隐患；②按采集顺序前 75% 后 25% 划分——顺序往往与产地/日期混杂，等于把整个产地拿去考试。

**自查**：`fig3_spxy_*.png` 那张图——预测集点均匀嵌在校正集覆盖范围内，最高最低值都在校正集。

### 3.6 第 6 步：CARS 变量筛选 + PLS 建模 ★

**目标**：每个成分筛出特征波长，建立精简、稳健、可解释的 PLS 模型。

**做法与参数**（`chemlib.cars_select`，均为文献常规值）：

```
蒙特卡洛轮数: 50        每轮抽样比例: 0.8(80%建模, 20%验证)
EDF: 保留数从 p 指数衰减到 2
最优轮判据: 1-SE 规则(可切换 rule="min" 复现原始论文判据)
潜变量数: 10折交叉验证自动选(1~10)
随机种子: 固定并写进论文(可复现性)
```

**结果解读三件套**：`fig4_cars_*.png` 看筛选过程（变量数衰减+误差曲线）；`fig5_select_*.png` 看选中波长落在哪些峰；`selected_wavelengths_*.csv` 是明细。**论文里必须做的一步对照**：把选中波长与你引的文献吸收峰归属表并排解释——筛选结果落在 1450/1940/2050/2100/2180/2270/2324 nm 附近就是物理上正确的证据。

**常见坑**：①CARS 每轮 RMSECV 抽样噪声大，直接取全局最小容易停在变量很多的轮（本复现 qingke 蛋白 434 vs 31 个变量的对比就是演示）；②忘了报告 CARS 的随机种子与轮数，别人无法复现；③变量筛选后再用全谱预处理流程但坐标没对齐（代码里筛选作用在预处理后的矩阵上，下标一致）。

**自查**：CARS-PLS 与全谱 PLS 并列表格；选中波长数、位置、与文献峰的对应关系三样齐全。

### 3.7 第 7 步：模型验证 ★

**目标**：证明模型不是"背题"而是"会做题"。

**做法（三层验证，逐级加强）**：

1. **内部验证**：校正/预测集指标全套（Rc、RMSEC、Rp、RMSEP、RPD、RPIQ），预测-实测散点图（`fig6_pred_*.png` 格式，1:1 线+指标框）；
2. **划分稳定性**：换 5 个随机种子重新 SPXY 划分，全流程重跑，报告 Rp/RMSEP 的均值±标准差（本复现已内置，见 4.3/4.4 表）。若 5 次结果波动大，说明模型对"哪些样本被选中"敏感，样本量或代表性不足；
3. **外部验证**（毕设强烈建议做）：留 10~20 个"完全没参与任何调参"的样品（另一年收获/另一产地/实验室没动过的）做最后一考。答辩时这一项最能加分。

**判据落点**：Rp ≥ 0.90 且 RPD ≥ 2.5~3，即可下"可用于快速检测"的结论；同时报告 RMSEP 的物理含义（"水分预测平均偏差 0.2 个百分点"这种话说给非专业评委听）。

**常见坑**：①只报 Rc 不报 Rp（或反之）；②预测集样本参与过任何预处理参数计算（如 MSC 参考）——信息泄露；③RPD 低时只字不提含量范围窄的客观原因，答辩被问住。

**自查**：论文结果表列全六指标；有 5 种子稳定性；散点图标了 1:1 线和 n。

### 3.8 第 8 步：论文与答辩

**论文结构建议**（工科毕设典型五章）：

```
第1章 绪论: 研究背景与意义 / 国内外研究进展(谷物NIR→大麦青稞NIR→方法学) / 研究内容与技术路线
第2章 材料与方法: 样品(表1 产地×品种×数量) / 参考值测定(国标) / 光谱采集(参数表) /
                  预处理方法 / SPXY / CARS / PLS / 评价指标 —— 公式全部给出

                  3.2 预处理优选(7种×3成分全表+光谱图)

```

**高频答辩问题预演**（按被问概率排序）：

1. 为什么选 PLS 不用神经网络？→ 样本量几十个，PLS 是小样本高维共线数据的标准解；深度学习需要大样本，可作展望。
2. CARS 筛出来的波长有什么物理意义？→ 拿 3.6 节对照表回答（这是送分题，务必准备好）。
3. RMSEP 0.2% 意味着什么？→ 现场抽检水分预测平均偏差 0.2 个百分点，满足快速筛查。
4. 为什么水分比淀粉好测？→ O–H 吸收系数大、1940 nm 峰强且专属；淀粉是"余量"成分，与蛋白/纤维负相关，信号被稀释。
5. 预测集怎么选的、会不会泄露信息？→ SPXY 原理+MSC 参考只用校正集。
6. 换个品种还准吗？→ 外部验证结果；诚实说明模型边界（训练分布内才可靠）。
7. 预处理为什么选 X？→ RMSEP 对比表；坦承"数据说话，不迷信组合"。
8. 样本量够吗？→ 引用同类研究样本量区间+稳定性验证波动小说明。

## 4. 最小系统验证复现

### 4.1 复现策略：一真一仿，双轨闭环

你的题目要求"真的划分创建数据集，而不是简单跑个脚本"。检索结论：**公开渠道目前没有可直接下载的"黑青稞 NIR 光谱+成分参考值"数据集**（知网相关论文均未公开数据；这也是你毕设的价值之一——你测的数据集本身就能成为成果）。因此本复现走双轨：

- **真实数据轨（corn 基准）**：国际化学计量学标准考核数据集，80 个玉米样品、3 台仪器、水分/油分/蛋白/淀粉参考值齐全，被 CARS 原文等上千篇论文用作算法基准。用它验证**整条算法链的正确性**——如果我们的 PLS/CARS 在这份被反复研究的数据上得到与文献一致量级的结果，实现就没有 bug。
- **仿真数据轨（qingke 仿真）**：按文献报道的黑青稞成分范围（水分 8~12.5%、蛋白 9~16%、淀粉 51~72%、蛋白-淀粉负相关）与 NIR 吸收峰归属（1.3 节六峰）构造 180 个样本的物理仿真集（生成模型全部写在 `01_make_qingke_sim.py` 注释里，可改种子重建）。它有**已知真值的"埋入峰"**——CARS 若能从 700 个波长里把埋进去的吸收带找回来，就证明算法在"黑青稞场景"下真正在工作，而不是碰巧拟合。

真实毕业设计时，你只需把自己的实测 CSV 换进来（格式见 4.5 节），整条流水线原样重跑。

### 4.3 真实数据（corn）结果与解读

数据概况：80 样本，1100~2498 nm @2 nm（700 点）；水分 9.38~10.99%（SD 0.38）、蛋白 7.65~9.71%（SD 0.50）、淀粉 62.83~66.47%（SD 0.82）。SPXY 划分 60 校正 + 20 预测。

**最终模型（完整表见 `results/corn/metrics_final.csv`）**：

| 成分 | 最优预处理 | 模型 | 变量数 | Rc | RMSEC | Rp | RMSEP | RPD |
|---|---|---|---|---|---|---|---|---|
| 水分 | 原始光谱 | 全谱PLS | 700 | 0.9994 | 0.0142 | 0.9994 | 0.0135 | 22.8 |
| 水分 | 原始光谱 | CARS-PLS | **45** | 1.0000 | 0.0015 | 1.0000 | **0.0016** | **189.8** |
| 蛋白质 | 一阶导数 | 全谱PLS | 700 | 0.9939 | 0.0578 | 0.9802 | 0.0700 | 5.2 |
| 蛋白质 | 一阶导数 | CARS-PLS | **103** | 0.9983 | 0.0302 | **0.9892** | **0.0547** | **6.6** |
| 淀粉 | MSC+一阶导 | 全谱PLS | 700 | 0.9943 | 0.0951 | 0.9514 | 0.1465 | 3.1 |
| 淀粉 | MSC+一阶导 | CARS-PLS | **103** | 0.9962 | 0.0779 | **0.9663** | **0.1193** | **3.8** |

**解读（论文可直接借用的论证逻辑）**：

1. **与文献量级吻合 → 实现正确**。CARS 原文 [3] 及后续大量研究在该数据集上的蛋白 RMSEP 多在 0.05~0.15、Rp 0.95~0.99；我们 0.055/0.989 正落在区间内。水分信号极强（1940 nm 峰高且专属），Rp≈1.000 属预期。
2. **CARS 有效性**：三成分变量数 700→45/103/103，Rp 与 RMSEP 同时改善——筛选既压缩了模型又提了精度（去掉无信息变量=去掉噪声源）。
3. **选中波长回 literature**：水分模型 45 个变量的主簇在 **1904 nm**（水合频带）与 2109 nm；蛋白主簇 **2169/2034 nm**（蛋白 N–H 带）；淀粉主簇 **2071/2124/2300 nm**（淀粉 C–H/O–H 带）。真实数据上算法自己找到了教科书吸收带——这是答辩"波长物理意义"问题的满分素材。
4. **预处理不是越复杂越好**：水分最优是"原始光谱"（信号强、仪器好，校正反而引入失真）；蛋白要 D1 消基线；淀粉要 MSC+D1（对散射最敏感的成分用了最强校正）。三种成分三种答案，这就是"优选"二字的含义。
5. **稳定性**（5 种子重划分，均值±SD）：蛋白 CARS-PLS Rp=0.9881±0.0057、RMSEP=0.0555±0.0140；淀粉 CARS-PLS Rp=0.9517±0.0169。波动小说明样本划分不敏感。（注：SPXY 本身是确定性算法，种子只改变交叉验证折分与 CARS 抽样，因此全谱 PLS 的 ±0.0000 属正常。）

### 4.4 仿真数据（qingke）结果与解读

数据概况：180 样本；水分 8.01~12.45%（SD 1.22）、蛋白 9.07~16.00%（SD 2.00）、淀粉 50.96~71.76%（SD 3.26）、蛋白-淀粉相关 −0.22。SPXY 划分 135 校正 + 45 预测。仿真中刻意加入了 ±4% 乘法散射（整粒漫反射的主要干扰，深色种皮会更强）。

**最终模型（`results/qingke/metrics_final.csv`）**：

| 成分 | 最优预处理 | 模型 | 变量数 | Rc | RMSEC | Rp | RMSEP | RPD |
|---|---|---|---|---|---|---|---|---|
| 水分 | 一阶导数 | 全谱PLS | 700 | 0.9644 | 0.3242 | 0.9752 | 0.2813 | 4.26 |
| 水分 | 一阶导数 | CARS-PLS | 239 | 0.9643 | 0.3246 | 0.9751 | 0.2813 | 4.26 |
| 蛋白质 | 一阶导数 | 全谱PLS | 700 | 0.9779 | 0.4140 | 0.9871 | 0.3302 | 6.20 |
| 蛋白质 | 一阶导数 | CARS-PLS | **11** | 0.9770 | 0.4221 | 0.9838 | 0.3709 | 5.52 |
| 淀粉 | 一阶导数 | 全谱PLS | 700 | 0.8098 | 2.0479 | 0.8602 | 1.2187 | 1.97 |
| 淀粉 | 一阶导数 | CARS-PLS | **22** | 0.8094 | 2.0495 | **0.8643** | **1.2027** | 2.00 |

**解读**：

1. **CARS 找回了全部埋入峰（最有说服力的验证）**：水分模型 239 个选中变量中 158 个（66%）精确落在埋入的 1450 nm（×62）和 1940 nm（×96）水峰上；蛋白 11 个变量命中 2046/2190/2213 nm（埋入 2050/2180）；淀粉 22 个变量命中 2130~2138（埋入 2100）、2250/2254/2282（埋入 2270）、2358（埋入 2324 邻域）。散布在其它波长的少量变量对应成分间相关性（如淀粉模型选水峰邻域，因为水分与淀粉含量负相关）。**从 700 个候选里精准捞回埋进去的化学指纹——整条流水线的正确性在"黑青稞场景"下闭环。**
2. **淀粉最难，和真实文献一致**：RPD≈2.0（筛查级）。原因在数据构造里就写着：淀粉含量与蛋白负相关、特征峰与蛋白峰部分重叠、单位含量吸光度系数低于水。Li et al. 2025 [1] 的青稞淀粉模型同样是五个参数中较弱项。改善路径：扩大样本量与含量范围（RPD 的分母是 SD）、增加品种覆盖。
3. **SNV/MSC 在此数据上反而失分**（水分 Rp：D1 0.975 vs SNV 0.947）：SNV 把每条光谱整体归一时，也把弱化学信号的绝对幅度归掉了。真实黑青稞上哪种最优要靠自己的数据重新比——本复现给的正是这套对比流程。
4. **1-SE 规则的实证**（蛋白）：min 判据选 434 变量 Rp=0.9968；1-SE 选 11 变量 Rp=0.9838——变量砍 98%，仍保持 RPD 5.5。窄波段便携仪器（只装 11 个波长的滤光片型设备）的可行性论证就靠这类结果。
5. **稳定性**（5 种子）：水分 CARS-PLS RMSEP=0.2924±0.0196、蛋白 0.3447±0.0150、淀粉 1.3487±0.2238。前两者稳定；淀粉 CARS 模型波动偏大——22 个变量的小子集模型对 CARS 抽样随机性更敏感（任一轮漏选关键峰，误差就上去）。这提示真实数据上淀粉建模宜适当放宽 1-SE 阈值或增大 n_runs，论文里如实讨论比藏起来更专业。

## 6. 常见问题与避坑清单

**Q1 预测集指标比校正集还好（Rp > Rc），是赚了吗？**
不是 bug 也不用慌：预测集只有 20~45 个样本，相关系数估计本身有抽样波动，且 SPXY 把极值放进了校正集。报告时如实写，别当成"模型无过拟合"的证据。

**Q2 CARS 筛出的变量为什么有的不在任何文献峰上？**
正常。成分间相关性强时（淀粉与蛋白负相关），对方峰位置的变量对你的模型也有预测价值。论文里挑主簇解释，其余归因于"相关成分间接信息"。

**Q3 我的数据 SPXY 划分后预测集只有十几个样本，指标可信吗？**
样本 <60 时 3:1 的预测集确实太小，这是样本量问题不是方法问题。补救：改用 5 折或留一交叉验证报告交叉验证指标（本库 `select_ncomp_cv` 改一下可复用），并在论文局限里说明。

**Q4 想加 SVM/随机森林对比，可以吗？**
可以，答辩也常被问。建议顺序：先 PLS 打牢（毕设主线），有余力加 LS-SVM 或 RF 作对比章节。`chemlib` 的数据结构（X 矩阵+y 向量）可直接喂给 sklearn。

**Q5 光谱一端噪声很大（如 2400~2500 nm 信噪比差），能截掉吗？**
能且应该，这是常规操作（信噪比差的波段先截断）。在 `load_data` 后对 X 和 wl 做同样的切片即可，论文注明保留波段范围。

**Q6 需要测 β-葡聚糖/花青素加做模型吗？**
黑青稞特色成分，加做是加分项（Li 2025 [1] 做了 β-葡聚糖）；但化学值测定成本高（试剂盒/ HPLC），量力而行。

**Q7 一阶导数光谱看着像噪声毛刺？**
SG 求导窗口太小。窗口从 11 起试（本复现参数），或检查原始光谱噪声水平；毛刺明显就加大窗口，论文报窗口宽度。

**Q8 毕设时间怎么排？**
反推：答辩前 1 周定稿 → 前 3 周完成全部建模图表 → 中期前完成采谱与化学值（这是最大风险项，仪器排队/化学实验失败都可能卡住，越早启动越好）→ 第 1 个月完成文献+采样方案。样本化学值测定是最长的单任务，优先排。

## 附录 A 术语表

| 术语 | 一句话解释 |
|---|---|
| NIR 近红外 | 800~2500 nm 光波段，分子振动倍频/合频吸收区 |
| 吸光度 A | A=log₁₀(1/R)，与浓度近似线性 |
| 漫反射 | 光进入颗粒样品经多次折射反射后返回，整粒测量的主要方式 |
| 散射 | 颗粒物理差异造成的整条光谱高低变化，与化学无关的干扰 |
| 基线漂移 | 光谱整体的平移/倾斜，装样与仪器漂移所致 |
| 校正集/预测集 | 训练模型的样本 / 独立考试的样本 |
| 潜变量 (LV) | PLS 从光谱中提取的复合变量，相互正交 |
| RMSECV | 交叉验证均方根误差，选潜变量数的依据 |
| 过拟合 | 模型背下了训练集噪声，考试（预测集）就露馅 |
| 倍频/合频 | 振动能级跃迁 2 倍频 / 两种振动叠加，NIR 吸收的来源 |
| RPD/RPIQ | 预测能力相对样本自然波动的倍数，跨研究可比指标 |

## 附录 B 公式速查卡

```
吸光度        A = log10(1/R)
SNV          x̃ = (x − mean(x)) / std(x)                          逐条光谱
MSC          x ≈ a·ref + b  →  x̃ = (x − b)/a                    ref=校正集均值光谱
SG 一阶导     D1[i] = d/dλ (窗口内 poly 拟合)                      窗口 11、阶数 2
SPXY 距离    D(i,j) = dx(i,j)/max(dx) + dy(i,j)/max(dy)          dx=光谱欧氏距离
RMSE         √( mean( (y − ŷ)² ) )
Rp           corr(y_pred, ŷ_pred)
RPD          SD(y_pred)/RMSEP        RPIQ:  IQR(y_pred)/RMSEP
PLS 预测     ŷ = ȳ + (X − x̄)·B ,  B = W (PᵀW)⁻¹ q               NIPALS 提取 W,P,q
```

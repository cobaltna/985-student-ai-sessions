# 第一部分 知识点精讲

## 第 1 章 市场营销与市场营销学

### 1.1 市场：四个角度，一个结论

同一个词「市场」，四类人有四种说法，考试常拿来做区分。

| 角度 | 对市场的理解 | 关键词 |
|---|---|---|
| 日常生活 | 买卖的场所 | 时间、空间 |
| 经济学家 | 商品交换关系的总和，供求关系 | 经济实质 |
| 管理学家 | 供需双方共同认可条件下的交换活动 | 具体交换活动 |
| 营销学家（科特勒） | 卖方是「行业」，买方是「市场」 | 站在卖方角度看买方 |

教材给出的定义要能背：

> **市场是商品经济中生产者与消费者之间为实现产品或服务的价值，所进行的满足需求的交换关系、交换条件和交换过程的统称。**

这句话里有三个词要抓住：**交换关系、交换条件、交换过程**。

现实市场存在的三个条件：

1. 有消费者（用户）一方，有需要或欲望，并拥有可交换的资源；
2. 有生产者（供给者）一方，能提供满足需求的产品或服务；
3. 有促成交易的条件，如诚信、法律保障、双方可接受的价格、时间、空间、信息和服务方式。

再记一句结论：**市场的发展本质上由买方决定、由卖方推动，买方需求是决定性的。**

> 记忆钩子：市场 = 人（有需要）+ 货（能满足）+ 规则（能成交）。

### 1.2 市场营销的定义

三个版本的 AMA 定义，考「时间—内容」的对应：

| 年份 | 核心表述 | 时代特征 |
|---|---|---|
| 1960 | 为引导货物和劳务从生产者流转到达消费者或用户所进行的一切企业活动 | 流通环节 |
| 1985 | 对理念、货物和劳务的构想、定价、促销和分销的计划与执行过程，以创造达到个人和组织目标的交换 | 扩展到理念，强调计划与执行 |
| 2007 | 创造、传播、传递和交换对顾客、客户、合作者和整个社会有价值的市场供应物的一种活动、制度和过程 | 加入「社会价值」「制度和过程」 |

科特勒的两个定义：

- **管理定义**：选择目标市场，并通过创造、传递和传播卓越顾客价值，来获取、维持和增加顾客的艺术和科学。
- **社会定义**：一个社会过程，个人和团体通过创造、提供和与他人自由交换有价值的产品与服务来获得所需所求。

从管理定义里提炼三个要点（简答题常考）：

1. 基本目标是「**获取、维持和增加顾客**」；
2. **交换**是市场营销的核心；
3. 交换能否高效顺利进行，取决于**创造的产品和价值满足顾客需求的程度**，以及**管理交换过程的水平**。

### 1.3 六个核心概念（本章最容易被出题的地方）

**（1）需要、欲望、需求**

| 概念 | 定义 | 关键判断 |
|---|---|---|
| 需要 Needs | 人们与生俱来的基本要求（吃、穿、住、安全、归属、受尊重、求知、自我实现） | 营销者**不能创造**需要，只能以不同方式满足 |
| 欲望 Wants | 想得到能满足需要的**具体满足品**的愿望，受文化和个性影响 | 营销者**可以影响、塑造**欲望 |
| 需求 Demands | 有**支付能力**并愿意购买某个具体产品的欲望 | 欲望 + 购买力 = 需求 |

举例：口渴是需要；想喝可乐是欲望；买得起且愿意买一瓶可乐是需求。法国人想吃鹅肝、中国人想吃火锅，是欲望的差异；吃不起鹅肝，就还没有形成需求。

> 课件原话：营销者不能创造需要，但可以塑造和强化欲望；没有购买力支撑的欲望不构成需求。

**（2）市场细分、目标市场、定位（STP）**

- 细分：通过识别人口、心理、行为差异，把市场分成若干顾客群；
- 目标市场：选择进入具有最大机会的细分市场；
- 定位：在目标顾客心中建立能提供某些关键利益的形象。

**（3）产品和服务**

营销学里的产品是**能够满足人的需要和欲望的任何事物**，其价值在于带来欲望的满足。人们买轿车不是要一台机械，而是要交通服务。产品是获得服务的**载体**，可以是有形物品，也可以是人员、地点、活动、组织、观念。

**（4）效用、费用和满足**

- 效用：消费者对产品满足其需要的**整体能力**的评价，是主观评价；
- 消费者在效用与费用之间权衡，追求「每一元花费带来最大效用」。

**（5）交换、交易、关系**

| 概念 | 含义 | 关系 |
|---|---|---|
| 交换 | 从他人处取得所需之物，以某种东西作为回报的行为 | 市场营销的**核心概念** |
| 交易 | 交换双方之间的价值交换，是交换的基本组成单位 | 达成协议即发生交易 |
| 关系营销 | 与有价值的顾客、分销商、供应商等建立、保持并加强长期合作关系 | 宗旨从「每次交易利润最大化」转向「共同长期利益最大化」 |

交易两种方式：货币交易、非货币交易（以物易物、以服务易服务）。

**（6）市场营销与市场营销者**

交换双方中更主动、更积极寻求交换的一方是**市场营销者**，另一方是潜在顾客。市场营销者可以是卖方，也可以是买方；双方都积极时叫**相互市场营销**。

### 1.4 市场营销与企业职能

德鲁克的三句话必须记牢：

1. 「**顾客是企业得以生存的基础，企业的目的是创造顾客**」；
2. 「**市场营销和创新，这是企业的两个功能**」；
3. 「**营销是企业与众不同的独一无二的职能**」。

三条理由：

- 企业作为交换体系的一员，必须以顾客的存在为前提，没有顾客就没有企业；
- 顾客决定企业的本质，顾客的感受与价值判断决定企业命运；
- 企业最显著、最独特的功能是市场营销，生产、财务、人事只有在他实现营销职能的前提下才有意义。

**市场营销 ≠ 销售。** 营销的核心是清楚了解顾客，使企业提供的产品适合顾客需要；营销的目标是要**减少推销工作，甚至使销售行为变得多余**。

企业未能全面贯彻营销职能的四个原因：

1. 现代市场营销是较新的学科，人们常把推销、广告等次要功能误认为营销；
2. 企业各职能部门的认识差异，营销工作常受其他部门抵制；
3. 组织及其成员接受营销观念有一个过程，甚至会有反复；
4. 企业顺利成长时期最容易忘记营销原则，偏离轨道。

### 1.5 市场营销学的形成与发展（时间线必须记准）

| 阶段 | 时间 | 标志性事件 |
|---|---|---|
| 形成 | 1900—1930，美国 | 1902—1905 密歇根、加利福尼亚、伊利诺伊、俄亥俄等大学开设课程；**1910 年巴特勒出版《市场营销方法》，首次用 Marketing 作学科名称**；1918 克拉克《市场营销原理》讲义（1922 出版）；1920 邓肯《市场营销问题与方法》 |
| 发展 | 1929—1933 大危机后 | 供过于求，企业重视市场调查，提出「创造需求」；1937 年美国市场营销学和广告学教师协会与市场营销学会合并成立 **AMA** |
| 革命 | 二战后 | 把「**潜在需求**」纳入市场概念；市场由生产过程的**终点**转为**起点**；确立以消费者为中心 |

「革命」的实质一句话：**市场从生产的终点变成生产的起点，企业从以生产者为中心转向以消费者为中心。**

中国部分抓四个节点：

- 1933 丁馨伯编译《市场学原理》，复旦大学铅印（1934 世界书局出版）；
- 1978—1983 重新引进的启蒙阶段；
- 1984—1994 迅速传播（1984 长沙成立全国高等财经院校、综合性大学市场学教学研究会，1987 改名中国高等院校市场学研究会）；
- 1991 年 3 月中国市场学会在北京成立；1995 年「第五届市场营销与社会发展国际会议」标志进入新阶段。

### 1.6 学科性质、宏观与微观、研究意义

- 理论基础：**生产目的论**和**价值实现论**；核心概念是**交换**；方法是系统论、信息论、决策论。
- **宏观市场营销学**：从社会总体交换层面研究，以社会整体利益为目标，研究营销系统的社会功能与效用。
- **微观市场营销学**：从个体（个人或组织）交换层面研究，企业为实现目标而预测顾客需要、引导产品从生产者流向消费者。
- 研究意义三条：迎接新经济时代的营销挑战；促进经济成长；促进企业成长。

## 第 2 章 市场营销管理哲学及其贯彻

### 2.1 市场营销管理 = 需求管理

定义：企业选择目标市场，通过创造、传播和传递优质的顾客价值，建立和发展与目标市场之间的互利交换关系而进行的**分析、计划、执行与控制**过程。

> **本质是需求管理。** 任务是管理目标市场的**需求水平、时机和构成**。

八种需求状况与对应任务，是全章最高频的考点，必须一一对应：

| 需求状况 | 含义 | 营销管理任务 |
|---|---|---|
| 负需求 | 多数人不喜欢，甚至愿付代价回避（如高胆固醇食品） | **改变营销**（重新设计产品、降价、积极促销），把负需求转为正需求 |
| 无需求 | 对产品缺乏兴趣、漠不关心（陌生产品、与习惯冲突的产品、废旧物资） | 设法把产品好处与人的需要、兴趣**联系起来** |
| 潜伏需求 | 现有产品或服务尚未满足的、隐而不现的需求（无害香烟、智能汽车、癌症特效药） | 致力于**市场调研和新产品开发** |
| 下降需求 | 需求呈下降趋势 | 分析原因，开辟新市场、改变产品特性、更有效促销，**重新刺激需求** |
| 不规则需求 | 不同季节、不同时段波动很大（宾馆、公园、公交、博物馆） | **灵活定价、大力促销**，改变供需的时间模式 |
| 充分需求 | 需求水平与时间同预期一致 | 监测偏好与竞争、测评满意度、提高质量，**维持**现有水平 |
| 过度需求 | 需求超过企业能供给或愿供给的水平 | **低营销**：提价、合理分销、减少服务和促销 |
| 不健康需求 | 对有害物品或服务的需求（香烟、淫秽书刊） | **反市场营销**：用道德和法律手段约束或杜绝 |

> 记忆法：负需求「扭转」、无需求「连接」、潜伏需求「开发」、下降需求「刺激」、不规则需求「协调」、充分需求「维持」、过度需求「降低」、不健康需求「杜绝」。

### 2.2 五种营销管理哲学（本章的骨架）

核心问题：**如何处理企业、顾客、社会三者之间的利益关系。**

| 观念 | 中心 | 核心假设 | 典型口号 | 盛行时期 |
|---|---|---|---|---|
| 生产观念 | 企业 | 消费者接受他能买到的**价格低廉**的产品，应提高效率、低成本、大众分销 | 我们生产什么，就卖什么 | 19 世纪末 20 世纪初 |
| 产品观念 | 企业 | 消费者最喜欢**高质量、高性能、有特色**的产品 | 酒香不怕巷子深（精益求精） | 与生产观念同期 |
| 推销观念 | 企业 | 消费者有购买惰性或抗衡心理，不推就不买 | 我们卖什么，就让人们买什么 | 20 世纪三四十年代 |
| 市场营销观念 | 顾客 | 实现目标的关键是比竞争者更有效地为目标市场创造、交付、传播顾客价值 | 顾客需要什么，我们就生产供应什么 | 20 世纪 50 年代后 |
| 全方位营销观念 | 社会整体利益 | 要考虑顾客、利益相关者和社会的长期利益 | 兼顾三者利益 | 20 世纪 70 年代后 |

前三个是**旧观念**（以企业为中心）；后两个是**新观念**（顾客导向、社会导向）。

**营销近视症**：产品观念和生产观念的必然后果——过分重视产品而忽视顾客需求。铁路行业以为顾客需要火车而不是运输，计算尺制造商以为工程人员需要计算尺而不是计算能力。

**推销观念 vs 市场营销观念**（莱维特对比图，四行四列）：

| | 出发点 | 中心 | 方法 | 目标 |
|---|---|---|---|---|
| 推销观念 | 厂商 | 产品 | 推销和促销 | 通过扩大消费者需求获取利润 |
| 市场营销观念 | 目标市场 | 顾客需求 | 协调市场营销 | 通过满足消费者需求创造利润 |

**市场营销观念的四个支柱**：目标市场、整体营销、顾客满意、盈利率。

### 2.3 全方位营销观念

包含四个部分，缺一不可：

| 组成 | 要求 |
|---|---|
| 关系营销 | 与顾客、供应商、分销商、营销伙伴建立长期、互惠的满意关系，形成营销网络 |
| 整合营销 | 设计并整合营销活动与项目，使创造、传播、传递价值的能力最大化 |
| 内部营销 | 雇用、培训、激励有能力的员工，使其更有效地为顾客服务 |
| 绩效营销 | 审视营销的商业回报，并关注营销对法律、伦理、社会、环境的影响 |

与市场营销观念的关键差别：市场营销观念认为顾客利益满足必须符合企业利润目标，两者冲突时利润优先；全方位营销观念要求同时考虑**顾客需求、顾客和社会的长远利益、企业及伙伴的营销效益**。

### 2.4 顾客满意与顾客感知价值

**顾客满意**：顾客将产品和服务满足其需要的**感知效果**与其**期望**进行比较所形成的感觉状态。

- 绩效 < 期望 → 不满意
- 绩效 ≈ 期望 → 满意
- 绩效 > 期望 → 十分满意

期望的来源：以往的购买经验、朋友和同事的影响、营销者和竞争者的信息与承诺。
期望定得太高 → 顾客失望；定得太低 → 吸引不到顾客。

**顾客感知价值 CPV**：

> CPV = 顾客购买总价值 − 顾客购买总成本

| 总价值（4 项） | 总成本（4 项） |
|---|---|
| 产品价值：功能、特性、品质、品种与式样，是**首要因素** | 货币成本：价格，是**主要因素** |
| 服务价值：介绍、送货、安装、调试、维修、技术培训、质量保证 | 时间成本：等候、寻找、购买所耗时间 |
| 人员价值：员工的经营思想、知识水平、业务能力、效率、作风、应变能力 | 精力成本：精神与体力耗费 |
| 形象价值：产品、技术、质量、包装、商标、工作场所等有形形象，员工行为形象，理念形象 | |

运用 CPV 概念要注意三点：

1. 总价值与总成本各构成因素**相互影响**，不是独立的；
2. 不同顾客群对价值期望和成本重视程度不同；
3. CPV 高低应以**能实现企业经营目标**为原则，长期不适当追求最大化会使成本过高、利润下降。

**顾客忠诚**：顾客满意是顾客忠诚的重要条件，但两者关系受行业竞争程度影响。高度竞争市场（汽车、个人电脑）中，满意与完全满意的顾客忠诚度差异巨大；非竞争市场（管制下的垄断市场）中，无论满意与否都保持高度忠诚。

**顾客占有率**：不再追求赢得大量顾客的部分业务，而是争取现有顾客的全部业务。

### 2.5 全面质量管理（TQM）

- 质量定义（美国质量管理协会）：一项产品或服务有能力满足明确的或隐含的需求的各种属性和特征的总和——这是**顾客导向**的定义。
- **符合性质量**：产品达到能实现某种特定功能的质量水平。
- **适用性质量**：产品达到没有缺陷且稳定一致的性能。
- 关键结论：重要的是「**市场驱动质量**」，而不是「工程驱动质量」。100 万元的车满足其目标市场要求就是优质车，15 万元的车也一样。
- TQM 要求全员全程参与。八条要求中常考：质量必须能为顾客所感知；质量必须在每一项活动中体现；质量要求全体员工承诺；要求高质量合作伙伴；必须不断改进；有时需要总体突破；**质量追求未必要求更高成本**（质量是设计进去的，不是检查出来的）；保证质量是必要的但不是充分的制胜条件。

### 2.6 价值链

**企业价值链**：企业价值创造中互不相同但又互相关联的经济活动的集合。

| 基本增值活动（5 项，生产经营环节） | 辅助性增值活动（4 项） |
|---|---|
| 材料供应（进货后勤） | 企业基础结构与组织建设 |
| 生产加工 | 人力资源管理 |
| 成品储运（发货后勤） | 科学技术开发 |
| 市场销售 | 采购管理 |
| 售后服务 | |

辅助活动发生在所有基本活动的全过程中。

上下游的差别：**上游环节重心是创造产品价值**，与产品技术特性紧密相关；**下游环节重心是创造顾客价值**，成败取决于顾客服务。

**核心业务流程**（四条）：新产品实现流程、存货管理流程、订单—付款流程、顾客服务流程。

**供销价值链**：企业价值链向外延伸，由供应商、分销商和最终顾客组成的价值链。竞争由单个公司之间转变为**整个网络团队之间**。

**战略环节**：真正创造价值的经营活动。抓住战略环节就抓住了整条价值链；战略环节因行业而异——**高档时装是设计能力，餐饮业是地点选择，烟草业是公共关系**。精明做法是把战略环节控制在企业内部，非战略活动外包。

### 2.7 市场导向战略组织创新与学习型企业

市场导向战略规划的三个内容：把投资业务作为组合管理；按市场增长率与企业定位测算各业务单元未来利润空间；从长期战略高度制定规划。四个组织层次：企业、部门、业务、产品。

组织创新四件事：满足利益方的要求（原则是**满足每一个利益团体的最低期望**）、改进关键业务过程、合理配置资源、组织革新。

**学习型企业的三步**：

| 步骤 | 含义 | 要点 |
|---|---|---|
| 倾听（探察） | 企业感知外部世界的所有活动 | 听取**顾客、社区、企业**三个群体的声音；不能只依赖市场调研部门 |
| 学习 | 把信息转化为情报、知识、理解和智慧 | 个人知识 → **组织知识**（不是所有人知识的总和，是相关的、共同的、被一致认可的部分） |
| 领先 | 通过决策过程比竞争对手做得更好 | 建立决策网络：以资源分配定义决策；建立以市场为依据的决策方法 |

## 第 3 章 企业战略与营销管理

### 3.1 战略的特征与层次

**五个特征**：全局性、长远性、抗争性、纲领性、相对稳定性。

- 全局性：以企业大局为对象；
- 长远性：谋求长远目标；
- 抗争性：与对手抗衡的纲领，区别于一般运营计划；
- 纲领性：原则性、概括性，需分解落实；
- 相对稳定性：不能朝令夕改，但要随环境动态调整。

**三个层次**（安绍夫）：

| 层次 | 别称 | 回答的问题 | 制定者 |
|---|---|---|---|
| 总体战略 | 公司层战略 | 应该选择、进入和开展哪些类型的业务；经营范围与资源配置 | 企业高层 |
| 经营战略 | 业务单元战略、竞争战略 | 选定业务后，如何在相关领域开展活动与竞争 | SBU / 事业部 |
| 职能战略 | 职能层战略 | 营销、生产、财务、人力资源、研发各自怎么做 | 各职能部门 |

关系：职能战略服从经营战略，经营战略服从总体战略。**各职能以营销职能为主导**，生产、研发、财务、人力资源都是营销的支持性职能。

**战略规划的一般过程**（图 3-2 的逻辑链）：

> 环境（机会、威胁）→ 企业目标（优势、劣势）→ 战略计划 → 组织结构 → 制度体系 → 评估反馈（循环）

注意方向：先看环境，再定目标，再选战略，再改组织。反过来「从现有组织结构出发找机会」是守株待兔。

### 3.2 总体战略四步

**第一步：认识和界定企业使命**

使命 = 企业之所以存在的理由和价值，回答「为谁创造价值、创造什么价值」。

三个思考维度：

| 维度 | 含义 |
|---|---|
| 愿景 Vision | 对企业未来的期望和描述，未来 10—20 年的发展蓝图 |
| 业务领域 | 产业（行业）范围、市场范围、纵向范围、地理范围 |
| 经营政策 | 指导各部门如何对待顾客、供应商、经销商、竞争者、公众，要缩小任意解释的空间 |

好的使命说明书要**有激励性、能鼓舞人心**，并有一定弹性和预见性。

**第二步：区分战略业务单元（SBU）**

SBU = 一个企业值得和必须为其制定专门经营战略的**最小的业务管理单元**。

区分依据：各项业务之间有无「**共同的经营主线**」——目前的产品、市场与未来的产品、市场之间是否存在内在联系。

两条实践要求：

- **坚持以需求为导向**，不要按产品特性或技术要素划分。设「胶卷」事业部，数码相机普及后必然被动；界定为「影像信息存储」就能顺理成章转向数码。
- **力求切实可行**，范围不能太宽。用「满足交通运输的需要」界定就过宽，交通工具、顾客、产品三个维度组合无数，反而无法制定战略。

**第三步：规划投资组合**

波士顿矩阵（BCG）：纵轴市场成长率，横轴相对市场占有率（本企业份额 ÷ 最大竞争对手份额），圆圈面积表示该业务收益占企业全部收益的比重。

| 象限 | 成长率 | 相对占有率 | 资源与现金 | 战略 |
|---|---|---|---|---|
| 问号 | 高 | 低 | 需要大量投入，前景不明 | 有所取舍，选择性投资 |
| 明星 | 高 | 高 | 仍需较多投入以跟上市场 | 持续投入，未来主要财源 |
| 奶牛 | 低 | 高 | 不需大量投入，回报好 | 维持，提供现金流 |
| 瘦狗 | 低 | 低 | 盈利少甚至亏损 | 出售或放弃 |

GE 矩阵（多因素投资组合矩阵）：纵轴市场吸引力（市场规模、年市场成长率、历史利润率等），横轴竞争能力（市场占有率、产品质量、分销能力等）。每个因素 1—5 分加权。九个区域分三个地带：

- **绿色地带**（大强、大中、中强）：开绿灯，增加投入、扩大业务；
- **黄色地带**（小强、中中、大弱）：开黄灯，维持投入水平和市场占有率；
- **红色地带**（小弱、小中、中弱）：开红灯，收割或放弃。

**第四步：选择业务成长战略**

| 类型 | 三种方式 | 含义与例子 |
|---|---|---|
| 密集式成长 | 市场渗透 | 现有产品 + 现有市场：让老顾客多买、抢对手顾客、吸引新顾客 |
| | 市场开发 | 现有产品 + 新市场：新细分市场或新地区（摄像机从单位进入家庭；手机从城市到乡村） |
| | 产品开发 | 新产品 + 现有市场：iPhone 5c/5s 的多色策略 |
| 一体化成长 | 后向一体化 | 把外购原材料、零件改为自产，并购供应商 |
| | 前向一体化 | 对成品深加工，自建渠道、并购下游 |
| | 水平一体化 | 并购性质相同、生产同类产品的企业 |
| 多角化成长 | 同心多角化 | 用原有技术特长进入新市场（冰箱厂做空调） |
| | 水平多角化 | 用不同技术服务现有市场（拖拉机制造商生产农药化肥） |
| | 综合多角化 | 新业务 + 新市场，与现有技术市场无关（软件公司做保健品、房地产），**风险最大** |

> 风险排序：同心 < 水平 < 综合。一体化风险低于多角化。

### 3.3 经营战略：五力与三种一般性战略

**波特五力**（决定行业吸引力）：

1. 行业内部竞争：由行业集中度、产品差异、进入退出障碍决定；产能过剩、固定成本高、退出障碍大 → 价格战、促销战、广告战。
2. 新进入者的威胁：取决于进入障碍与退出障碍的组合。**进入障碍高、退出障碍低**最理想（收益高且稳定）；**进入障碍低、退出障碍高**最差（风险大收益低）。
3. 替代品的威胁：功能类似、用途相近的不同产品；替代品价格越有吸引力，威胁越大。
4. 购买者的讨价还价能力：购买者集中、采购占比大、产品难差异化、转换成本低、价格敏感、有后向一体化可能 → 议价能力强。
5. 供应商的讨价还价能力：供应商由少数公司控制、无替代品、本企业不是其重要顾客、产品有差异、易前向一体化 → 议价能力强。

**三种一般性战略**（波特）：

| 战略 | 优势来源 | 市场范围 | 做法 | 风险 |
|---|---|---|---|---|
| 成本领先 | 低成本地位 | 全行业 | 加强成本控制：简化产品、改进设计、节约材料、降低人工、生产创新、自动化 | 对手开发更低成本方法；技术变化使资源失效；过度降成本导致质量下降 |
| 差异化 | 顾客感知到的独特性 | 全行业 | 产品、设计、工艺、品牌、特征、款式、服务形成独到之处 | 对手价格很低时顾客放弃特色；差异被模仿；过度差异化推高成本 |
| 集中（聚焦） | 低成本或差异化，二者择一 | 特定范围 | 集中于特定购买者群体、产品线某部分或某一地域市场 | 宽市场对手进入；细分市场被再细分；成本差异扩大抵消优势 |

波特的关键警告：**试图集所有战略优势于一身、采用模糊的非此非彼战略的企业，最终在哪一方面都没有优势，战略效果最差。**

三种战略的实施条件（课件表格的要点）：

- 成本领先需要：可持续的资本投资与利用能力、工艺工程技巧、严格劳动监督、产品设计易于生产、低成本分销系统；组织上要求严格成本控制、详细的控制报告、结构化分工与责任、以数量为目标的激励。
- 差异化需要：强大的营销能力、产品工程、敏锐的创新能力、强大的基础研究能力、质量或技术领先的声誉、行业内较长历史或善于学习他人技术、与渠道商合作密切；组织上要求研发/产品开发/营销紧密合作、用主观评价代替数量标准、氛围好能吸引高水准劳动力。

### 3.4 营销过程与管理

营销过程必须服从经营战略。选了成本领先，营销就要和 production、财务、人力、研发一起规划以降低成本为首要目标的职能战略。

**第一步：决定目标市场和定位（战略营销计划的「4P 过程」）**

| 步骤 | 英文 | 做什么 |
|---|---|---|
| 调研 | Probing | 掌握需要、欲望及变化趋势，了解自身优势与核心竞争力，发现评估机会、预测防范威胁 |
| 划分 | Partitioning | 市场细分，对潜在顾客及需求分类，评估各细分市场价值 |
| 优先 | Prioritizing | 目标市场选择，明确愿意进入和需要占领的细分市场 |
| 定位 | Positioning | 在选定目标市场为企业、品牌或产品树立特色，突出与竞争者的不同 |

**第二步：发展营销组合**

营销组合 = 一整套能影响市场需求的**企业可控性因素**：产品 Product、价格 Price、地点 Place、促销 Promotion。

四个特性：

| 特性 | 含义 |
|---|---|
| 可控性 | 由企业可控制和可运用的手段构成 |
| 动态性 | 不是固定搭配，改变一个因素就形成新的组合 |
| 复合性 | 每个大类下还有次一级、更次一级的因素 |
| 整体性 | 不是简单相加，要在统一目标下相互配合，追求大于局部之和的整体效应 |

**第三步：制订营销计划并实施、控制**

计划按层次分：品牌计划、产品类别计划、新产品计划、细分市场计划、区域市场计划、客户计划。按时间分：长期战略性营销计划、年度营销计划。

## 第 4 章 市场营销环境

### 4.1 环境的含义与四个特点

**市场营销环境**：存在于企业营销系统外部的**不可控制或难以控制**的因素和力量，是影响企业营销活动及其目标实现的外部条件。

| 特点 | 含义 | 例子 |
|---|---|---|
| 客观性 | 不以营销者意志为转移，有强制性和不可控性 | 企业改变不了人口、政治、法律、社会文化 |
| 差异性 | 不同国家地区宏观环境不同，不同企业微观环境不同；同一变化对不同企业影响不同 | 加入 WTO 对各行业影响不同 |
| 多变性 | 是动态系统，各因素随社会经济发展不断变化 | 短缺经济 → 过剩经济 |
| 相关性 | 各因素相互影响、相互制约，一个变化引起连锁变化 | 政治法律变动影响行业竞争者数量 |

**微观与宏观是主从关系**，不是并列关系：微观环境受制于宏观环境。

| | 微观营销环境 | 宏观营销环境 |
|---|---|---|
| 别称 | 直接营销环境、作业环境 | 间接营销环境 |
| 定义 | 与企业紧密相连，**直接**影响与制约企业营销能力的外界力量和因素 | 影响微观环境及企业营销活动的一系列巨大的社会力量和自然环境因素 |
| 构成 | 营销渠道企业、顾客、竞争者、社会公众 | 人口、经济、自然、科学技术、政治法律、社会文化 |

企业对环境不是完全被动：可以主动适应，也可以运用自身资源影响和改变环境（科特勒「大营销理论」：协调使用经济的、心理的、政治的、公共关系的手段）。

### 4.2 微观环境

**（1）营销渠道企业**

| 类型 | 说明 |
|---|---|
| 供应商 | 提供原材料、零配件、设备、能源、劳务、资金；影响产品的数量、质量、成本、价格、利润；要开拓多渠道、避免依赖单一供应商 |
| 经销中间商 | **拥有商品所有权**，如批发商、零售商 |
| 代理中间商 | **不拥有商品所有权**，如代理商、经纪人、生产商代表 |
| 实体分配公司 | 仓储物流，提供**时间效用和空间效用** |
| 营销服务机构 | 营销研究公司、广告公司、传播公司 |
| 财务中介机构 | 银行、保险公司，协助融资或分担风险 |

**（2）顾客**：企业最重要的环境因素，是营销活动的出发点和归宿。市场类型：消费者市场、生产者市场、中间商市场、非营利组织市场、政府市场（+ 国际市场）。

**（3）竞争者（按消费需求角度分五类，从远到近）**

| 类型 | 竞争层次 | 例子 |
|---|---|---|
| 欲望竞争者 | 满足**不同欲望**的不同类型产品 | 买耐用品 / 外出旅游 / 装修住宅 |
| 属类竞争者 | 满足**同一欲望**的**不同属类**产品（平行竞争） | 娱乐设备 / 新式家具 / 健身器材 |
| 产品形式竞争者 | 同一属类下的**不同形式**产品 | 大屏幕电视 / 摄像机 / 高级音响 |
| 品种竞争者 | 同一形式下的**不同品种** | 等离子 / 液晶 |
| 品牌竞争者 | 同一品种下的**不同品牌** | 长虹 / TCL / 康佳 |

> 记忆：欲望 → 属类 → 形式 → 品种 → 品牌，范围由宽到窄，竞争由远到近。

**（4）公众（七类）**：融资公众、媒介公众、政府公众、社团公众、社区公众、一般公众、内部公众。

### 4.3 宏观环境

**（1）人口环境**（人口是构成市场的首要因素：有购买欲望 + 有支付能力的人）

| 因素 | 关注点 |
|---|---|
| 人口总量 | 衡量市场潜在容量；世界人口持续增长 |
| 年龄结构 | 老龄化 → 银发市场（健康护理、娱乐、旅游）；出生率下降 → 儿童食品、童装、玩具受威胁，但年轻夫妇旅游、娱乐、在外用餐增加 |
| 地理分布 | 不同地区气候、资源、风俗不同，需求不同；城镇化改变消费结构 |
| 家庭组成 | 家庭生命周期七阶段（见下） |
| 人口性别 | 性别差异带来需求与购买习惯差异 |

**家庭生命周期七阶段**：未婚期（年轻单身）→ 新婚期（年轻夫妻无孩子）→ 满巢期一（有 6 岁以下幼童）→ 满巢期二（有 6 岁及以上儿童）→ 满巢期三（年纪较大夫妻，有能自立子女）→ 空巢期（身边无孩子的老年夫妻）→ 孤独期（单身老人独居）。

**（2）经济环境**

收入三个层次，考试常拿来区分：

| 指标 | 含义 | 作用 |
|---|---|---|
| 人均 GDP | 按人口平均的 GDP | 从总体上影响和决定消费结构与消费水平；GDP 总额反映市场总容量 |
| 个人可支配收入 | 个人收入减除税收和其他经常性转移支出后的实际收入 | 可用于消费或储蓄；衡量购买力水平 |
| 可任意支配收入 | 可支配收入减去维持生活的必需支出 | 影响消费需求变化**最活跃**的因素 |

支出：**恩格尔定律**——家庭收入越少，食物支出占比越大；收入增加，食物支出比率趋于减少，教育、卫生与休闲支出比率迅速上升。食物支出占个人总支出的比例叫**恩格尔系数**，系数越大生活水平越低。

消费结构与支出模式还受：家庭生命周期阶段、所在地区与供应状况、城市化水平、商品化水平、劳务社会化水平、食物价格指数与消费品价格指数变动是否一致影响。

储蓄与消费信贷：高储蓄率推迟现实消费支出、提高潜在购买力；消费信贷（短期赊销、分期付款、消费贷款）让消费者提前实现购买。

经济发展阶段（罗斯托六阶段）：传统社会 → 准备 → 起飞 → 成熟 → 大众消费 → 超越大众消费。

商业周期四阶段：繁荣、衰退、萧条、复苏。

通货膨胀：货币量超过实际需要量引起货币贬值、物价上涨，「需求过大、供给不足」。
通货紧缩：价格总水平持续下降、货币持续升值，「供给过剩、需求不足」。

**（3）自然环境**：资源短缺、环境污染、能源成本上升；对策是生态营销、绿色营销。

**（4）科学技术环境**：影响企业内部生产经营，改变营销策略、经营管理方式、零售业态和消费者购物习惯；新产品从进入市场到成熟的时间不断缩短。

**（5）政治法律环境**：政治制度与体制、政局稳定性、政府对市场的态度；国际上看「政治权力」（进口限制、外汇控制、劳工限制、绿色壁垒）与「政治冲突」。法律环境包括法律法规、贸易协定。

**（6）社会文化环境**：民族特征、价值观念、生活方式、风俗习惯、宗教信仰、伦理道德、教育水平、语言文字的总和。**主体文化**占支配地位，**次级文化**是种族、地域、宗教等分支。七个方面：教育水平、宗教信仰、价值观念、规范、语言、消费习俗、消费流行。

- 规范由价值观衍生，包括风俗、道德观、习俗；
- 消费习俗是历代传承的消费方式；
- 消费流行带来社会需求的一致性，时间上有稳定性（长短不一），空间上有地域性。

### 4.4 环境分析与营销对策（本章的落点）

**环境威胁**：环境中不利于企业营销的因素及其发展趋势对企业市场地位构成的挑战。
**市场机会**：由环境变化形成的对企业具有吸引力和利益空间的领域。机会实质上是消费者「**未满足的需求**」。

**威胁分析矩阵**：两个维度——潜在严重性（影响程度）× 出现可能性（概率）。

- 概率大、影响大（位置 3、5）：特别重视，制定对策；
- 概率小、影响大（位置 1、6）：密切监视；
- 概率大、影响小（位置 2、4、8）：充分重视；
- 概率小、影响小（位置 7）：不必过于担心，注意发展变化。

**机会分析矩阵**：两个维度——潜在吸引力（盈利性）× 成功可能性（企业优势）。

- 吸引力大、成功可能性大（3、7）：把握战机，全力发展；
- 吸引力小、成功可能性小（1、5、8）：改善自身条件，审慎开展；
- 吸引力小、成功可能性大（6）：关注趋势变化，及时采取措施；
- 吸引力大、成功可能性小（4、2）：找出原因，改善条件，化解不利因素。

**机会的三种分类**（易考匹配）：

| 分类 | 含义 |
|---|---|
| 环境市场机会 / 企业市场机会 | 环境机会对所有企业都在，但只有**理想业务和成熟业务**才是本企业最适宜的机会 |
| 行业市场机会 / 边缘市场机会 | 本经营领域内的机会 / 不同行业交叉结合部的机会；边缘机会进入难度更大，但可能存在市场空隙 |
| 目前市场机会 / 未来市场机会 | 现有环境变化中的机会 / 预测未来大量需求与消费倾向 |

**四种业务与对策**（机会水平 × 威胁水平）：

| 业务 | 机会 | 威胁 | 对策 |
|---|---|---|---|
| 理想业务 | 高 | 低 | 机会难得甚至转瞬即逝，抓住机遇、迅速行动 |
| 风险业务 | 高 | 高 | 不盲目冒进也不迟疑，全面分析优劣势，扬长避短，争取突破 |
| 成熟业务 | 低 | 低 | 作为常规业务维持正常运转，为理想业务和风险业务准备条件 |
| 困难业务 | 低 | 高 | 要么改变环境走出困境，要么立即转移 |

**SWOT**：优势 Strength、劣势 Weakness（内部）；机会 Opportunity、威胁 Threat（外部）。四种组合战略：

| 组合 | 名称 | 关注点 |
|---|---|---|
| SO | 增长战略 | 杠杆效应：抓住机会、发挥优势 |
| ST | 调整战略 | 脆弱性（优势不优）：克服威胁，或多种经营 |
| WO | 扭转战略 | 抑制性（能力跟不上环境）：追加资源，劣势转优势，战略转型 |
| WT | 防御或退出战略 | 问题性（挑战严峻）：考虑防御能力或退出 |

## 课件补充（L1—L3 独有、教材没有展开的内容）

这部分是老师上课讲过的，出题概率高，单独列出来。

### L1 营销概论

**（1）管理者的三项技能（罗伯特·卡茨）**

| 技能 | 含义 | 最重要的人群 |
|---|---|---|
| 技术技能 | 熟练完成工作任务所需的特定领域知识和技术 | 基层管理者 |
| 人际技能 | 与他人和团队良好合作的能力 | 所有层级都重要 |
| 概念技能 | 对抽象复杂情况思考概念化，把组织视为整体，理解各业务单元关系，设想组织如何适应环境 | 高层管理者 |

**（2）营销理念发展的四个阶段（课件的主线）**

| 阶段 | 英文 | 含义 |
|---|---|---|
| 1P | Marketing is Promotion | 营销即推广 |
| 4P | Marketing is Marketing Mix | 营销即营销组合（产品、价格、渠道、推广） |
| STP | Marketing is STP | 营销是营销战略：细分、目标市场、定位。营销被提升到战略高度 |
| ME | Marketing is Everything | 营销是一切：把营销作为驱动企业增长的战略，融入各部门，让整个公司以客户为导向（不是用营销取代其他职能） |

- 1910 年左右韦氏词典首次收录 Marketing，现代意义的营销仅有百年历史。
- 尼尔·鲍顿最先提出营销组合（marketing mix）概念；1960 年麦卡锡提出 4P，1967 年进入科特勒教材。
- 4P 的白话版：产品有物可买、价格买得起、渠道买得到、促销想去买。

**（3）4P 的两个缺点（课件明确讲的两点）**

1. **科学性上不是「不重不漏」的模型**。打折促销算 Price 还是 Promotion？有吸引力的包装算 Product 还是 Promotion？科特勒曾加到 6P（政治权力、公共关系），也有学者把 STP 加进来成为 10P。
2. **视角是企业中心、产品导向**，不是顾客中心。1990 年劳特伯恩提出 **4C**：

| 4P | 4C | 含义 |
|---|---|---|
| Product 产品 | Consumer solution | 顾客需要的解决方案 |
| Price 价格 | Cost | 顾客愿意支付的成本 |
| Place 渠道 | Convenience | 顾客购买的便利 |
| Promotion 促销 | Communication | 与顾客的双向沟通 |

**（4）顾客导向为什么在 1970 年代后才重要**

STP 观点提出后，企业不再服务所有市场，而是选细分市场、争心智定位。转变的条件是**细分市场开始具有盈利回报**：

- 需求端：消费者收入提高，细分市场需求量足够大；
- 生产端：技术进步降低成本，生产较小市场规模的商品也能控制成本。

课件的例子：1 万个买得起汽车的消费者里 20% 想要红色，只有 2000 人，成本高、不划算；100 万个消费者里 20% 想要红色，有 20 万人，规模经济让成本下降，盈利可能相当或超过黑色汽车。

**（5）营销是一个过程（流程图，课件要求能对应）**

> 理解市场和顾客的需求（MR）→ 设计顾客导向营销战略（STP）→ 构建传递价值的整合营销计划（4P 或 4C）→ 建立盈利性的关系和创造顾客愉悦 → 从顾客处获得回报以创造利润和顾客权益

记忆：**MR 管「看懂」，STP 管「选对」，4P 管「做到」，关系管「留住」，回报是「结果」。**

**（6）市场提供物（market offerings）**

4P 中的 Product 是广义概念，包括**有形产品、无形服务、带来愉悦感的体验**。体验较难界定，但消费者的愉悦感受是核心。卡尼曼的结肠镜实验说明：体验的评价取决于**峰值和结尾**，过程更长但结尾更温和的 B 方法，患者回忆起来反而觉得没那么疼。营销启示：要塑造更好、更愉悦、更难忘、更乐于分享的体验。

### L2 企业战略

**（7）战略管理的过程**：战略分析 → 战略选择 → 战略实施 → 评估调整。

**（8）SBU 与竞争战略的对应**：宝洁中国旗下秀发护理有 7 个品牌，每个都是不同的 SBU；飘柔实施低成本战略，沙宣实施差异化战略。SBU 是**竞争战略的实施单位**。

**（9）市场细分的四个因素（按可观测性分两组）**

| 组别 | 因素 | 特点 |
|---|---|---|
| 容易观察和测量 | 地理、人口 | 客观、易测量 |
| 难以直接观察和测量 | 心理、行为 | 主观、难测量 |

**（10）有效细分的三个标准**

| 标准 | 英文 | 含义 | 一句话判断 |
|---|---|---|---|
| 差异明 | differentiable | 细分市场在概念上和消费者需求上容易区分 | 确实存在 |
| 规模足 | substantial | 有效需求量足够，能有利可图 | 可以获利 |
| 可接近 | accessible | 通过分销渠道或媒体可以接近和渗透该市场 | 能够执行 |

课件例子：基础护肤品按性别细分，差异明；但 Z 世代男性越来越不介意选购传统女性品牌，差异在弱化。京东、当当能渗透全国文艺青年，实体书店只能渗透本地，说明可接近性不同。

**（11）大众市场 vs 细分市场**

- 大众市场：没有对性别、年龄、收入、特殊功效做较高程度细分，如可口可乐、青岛啤酒、农夫山泉；
- 细分市场：做了较高程度细分，如 Dr Pepper（味道独特）、手工精酿啤酒、依云矿泉水。

**（12）飘柔的战略转变（案例题的经典素材）**

| 时期 | 战略 | 证据 |
|---|---|---|
| 早期（1990 年代） | 差异化 | 300ml 约 12—14 元，高于国产 10 元；差异点是「柔顺飘逸」，实现方式是行业内第一款洗发水+护发素二合一 |
| 2004 年后 | 成本领先 | 降价至 9.9 元，直接价格竞争；750ml 装 36.8 元对蜂花 37.9 元 |

**（13）NeXT 的聚焦战略（说明聚焦战略的适用边界）**

1985 年乔布斯创办 NeXT，定位个人工作站、目标高校；定价 6500 美元而非预期的 2000—3000 美元，月销约 400 台。1989 年 SUN 发布 SPARCstation 1 重创 NeXT，被迫转向专业工作站市场（高校教育工作者、出版业者等非传统技术用户）。1991 年 NeXT 宣称在专业工作站「几乎追平 SUN」，但 SUN 总出货量是它的五倍。

要点：聚焦战略选对了细分市场，还要看**该细分市场的规模是否足够、竞争结构是否允许**；细分市场太小，即使占有率高也撑不起企业。

**（14）市场扩张矩阵（安索夫矩阵，与教材密集式成长一致）**

| | 现有产品 | 新产品 |
|---|---|---|
| 现有市场 | 市场渗透 | 产品开发 |
| 新市场 | 市场开发 | 多元化（多角化） |

课件例子（星巴克）：在中国继续新开门店 = 市场渗透；把门店开到印度等新国家 = 市场开发；收购鲜榨果汁店和茶商、用不同品牌和店铺 = 多元化。

**（15）云米案例的判断逻辑（品牌延伸）**

- coKiing（高端 AI 家电）：逆向跨阶，母品牌缺乏高端基因；核心能力错位（用互联网算法解决空调变频、制冷等基础物理性能）；资源内耗；结果惨淡退市（首款空调退货率 18%）。
- 泉先（专业净水）：正向延伸，复用母品牌「有技术、专业」的认知；能力协同（双 RO 反渗透）；资源高效复用（1500 家线下体验店）；结果成功（2020 年销售额 3.2 亿元）。

结论：品牌延伸要跟**母品牌的认知与核心能力**同向，跨越太大就是陷阱。

**（16）低成本 vs 差异化战略的实施条件（课件表格）**

| | 需要的一般资源和技能 | 常见的组织条件 |
|---|---|---|
| 总成本领先 | 可持续的资本投资和资本利用；工艺工程技巧；严格劳动监督；产品设计易于生产；低成本分销系统 | 严格成本控制；定期详细控制报告；结构化组织安排和责任；以严格数量目标为基础的激励 |
| 差异化 | 强大营销能力；产品工程；敏锐创新能力；强大基础研究能力；质量或技术领先的声誉；行业历史长或善于学习他人技术并以独特方式综合；与渠道商合作密切 | 研发、产品开发、营销紧密合作；用主观评价代替数量标准；组织氛围好，能吸引高水准劳动力 |

### L3 环境分析

**（17）战略分析的完整框架（课件开篇的框架图）**

> 外部环境分析：宏观用 **PEST**，行业用 **波特五力**；
> 内部分析：**价值链**；
> 内外部结合：**SWOT**；
> 市场分析：**STP**。

**（18）PEST 的四类因素与典型变量**

| 维度 | 典型变量 |
|---|---|
| Political 政治与法律 | 税法、反垄断法规、知识产权法、环境保护法、政治行动委员会、产业政策、投资政策、经济规划、大国和地区关系 |
| Economic 经济与人口 | GDP 及增长率、利率与贷款可得性、通货膨胀率、居民可支配收入、消费/储蓄倾向、就业率、人口结构、人口增长率、人口流动、家庭规模 |
| Social 社会与文化 | 教育状况、文化观念、工作观念、家庭观念、社会责任、道德观念、审美 |
| Technological 技术 | 研发投入、工业化程度、信息化程度、现有技术、可能的新技术替代、技术商业化速度 |

**（19）波特五力各力的具体判断因素（课件列得很细，判断题爱考）**

| 力 | 判断因素 |
|---|---|
| 行业现有竞争 | 厂商数量、产品差异化程度、成本结构、利润率、生命周期、战略 |
| 供应商议价能力 | 供应商集中程度、品牌强度、收益率、能否前向整合、质量和服务的地位、本行业是否其核心顾客群、本企业的转换成本 |
| 购买者议价能力 | 客户集中程度、产品差异化程度、客户利润率、质量和服务的地位、客户能否后向整合、客户转换成本 |
| 潜在进入者 | 行业经济规模、资金需求、技术需求、在位企业绝对成本优势、品牌忠诚度、转换成本、行政规制 |
| 替代品 | 替代品质量和服务、性价比、客户对替代品的态度、转换成本 |

**（20）瑞幸案例的五力对应（能复述即可）**

- 现有竞争：行业仍处成长期，我国人均咖啡消费量低于发达国家；对手是星巴克、Costa、便利店咖啡、快餐店咖啡；瑞幸用价格补贴和线上下单。
- 供应商：靠规模获得议价权，与路易达孚等合作。
- 购买者：C 端是写字楼白领，年轻、价格敏感，用差异化新品降低敏感度。
- 潜在进入者：快速发展抬高融资成本。
- 替代品：奶茶、精品咖啡、精品速溶，存在时空差异和规模差异。

**（21）价值链与微笑曲线**

- 价值链分析目的：考察企业各项活动及其相互关系，找出具有竞争优势的资源。
- 三条路径：降低成本同时维持价值；提高价值同时保持成本；两者同时做到。
- 宜家的价值链：总部设计 → 全球供应商竞价采购 → 自建/租赁配送中心（60—70% 直接从供应商运到商场）→ 直销与卖场选址设计 → 有限服务；**平板包装**同时降低了设计和运输成本。
- **微笑曲线**（施振荣，宏碁创始人，20 世纪 90 年代）：研发设计、营销品牌在两端，附加值高；生产制造在中间，附加值低。
- 课件补充的两点修正：制造环节也可以通过研发创新、技术创新、管理创新、模式创新谋求利润提升；甚至存在行业特例（如苹果，研发设计与品牌服务两端都强，净利率 19.2%）。

**（22）蜜雪冰城案例的核心结论**

- 蜜雪冰城本质是「卖食材」的公司：食材收入占比约 70%，包装材料约 16%。
- 自建原料生产（重庆雪王农业、四川雪王柠檬、大咖国际食品），自建物流与仓储，把加盟商的采购成本压到最低。
- 治理加盟商的办法不是严管，而是让供应**更便宜、更稳定**，让加盟商没有动力找别的货源。糖浆改用嘉吉的过滤液体糖浆，减少门店操作步骤，「让加盟商没有犯错的空间」。
- 柠檬案例：一年消耗约 5 万吨，产地无冷库则 5 月后要进口南非柠檬、价格翻倍；2020 年 9 月在安岳县成立四川雪王柠檬，通过合作社直接向农户收购，进口月份从 5 个月缩短到 2 个月。
- 这套做法在价值链上属于**后向一体化 + 上游战略环节控制**，在五力上降低了供应商议价能力，在 SWOT 上属于用优势补劣势（WO/ST 的综合运用）。

## 易混对比总表（考前最后看这一张）

| 对比项 | A | B | 区分关键 |
|---|---|---|---|
| 需要 / 欲望 / 需求 | 与生俱来的基本要求 | 满足需要的具体物品愿望 | 欲望 + 购买力 = 需求 |
| 交换 / 交易 | 以物易物的过程 | 达成协议的价值交换 | 交易是交换的基本单位 |
| 推销观念 / 营销观念 | 出发点厂商，中心产品，方法推销促销 | 出发点目标市场，中心顾客需求，方法协调营销 | 前者「卖我所有的」，后者「造顾客要的」 |
| 市场营销观念 / 全方位营销观念 | 顾客满意 + 企业利润 | 兼顾顾客、利益相关者、社会长期利益 | 冲突时谁优先 |
| 微观环境 / 宏观环境 | 直接影响，作业环境 | 间接影响，以微观为媒介 | 主从关系，不是并列 |
| 经销中间商 / 代理中间商 | 拥有商品所有权 | 不拥有所有权 | 有没有所有权 |
| 欲望竞争者 / 品牌竞争者 | 不同欲望的不同产品 | 同品种不同品牌 | 竞争范围由宽到窄 |
| 总体战略 / 经营战略 / 职能战略 | 进入哪些业务 | 在业务内如何竞争 | 营销战略属于职能战略 |
| 问号 / 明星 | 高成长、低占有率 | 高成长、高占有率 | 明星是发展良好的问号 |
| 成本领先 / 差异化 | 低成本地位，全行业 | 顾客感知独特性，全行业 | 优势来源不同 |
| 集中战略 | 特定范围，成本或差异二选一 | — | 范围窄 |
| 前向 / 后向一体化 | 向下游（深加工、自建渠道） | 向上游（自产原料） | 顺着物流方向为前向 |
| 同行多角化三型 | 同心（同技术） | 水平（同市场）；综合（全新） | 风险递增 |

| 个人可支配收入 / 可任意支配收入 | 扣除税收和转移支出 | 再扣除维持生活的必需支出 | 后者是最活跃因素 |

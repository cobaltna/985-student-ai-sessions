# 实验六（红外避障）·实验七（红外跟随）·实验八（寻光行走）

从本章起进入创新设计实验群。这三个实验共用一套代码框架：主循环里读两个传感器引脚的电平，按 4 种组合查表决定调用哪个运动函数。实验六用障碍物反射，实验七用跟随者反射（逻辑反过来），实验八用光敏电阻换了一种感知对象。框架一旦看懂，三个实验等于一个实验，后面的巡线（实验九）也只是把两路换成四路。

## 实验六 红外避障实验

### 6.1 实验定位

实验六是全书第一个"小车自己看着办"的实验。此前的实验一至五，小车做什么、什么时候做，全由程序里写死的延时决定；本实验开始，小车在 while(1) 里反复询问传感器"前面有没有东西"，再决定前进还是转向。指导书给出的目标：机器人在未知环境中自主行走、不碰撞障碍物，遇到障碍物能够智能绕行，可选功能为沿墙行走、迷宫探索。

练的能力：第一次把"感知—决策—执行"三段接成闭环；学会开关量传感器的电平约定与阈值调节。这个框架直接服务实验九（巡线状态机）和实验十（距离决策）。

### 6.2 预备知识

- 红外反射式检测：模块上有一对红外发射管和接收管。发射管发出一定频率的红外线，若前方有障碍物，红外线被反射回来被接收管接收；没有障碍物时红外线扩散衰减，接收管收不到。发射、接收、比较的活全在模块上完成，单片机只读一个结果引脚。
- 阈值电位器：反射回来的光强随距离衰减，"多强算检测到"由模块上的电位器（丝印 SW1）设定。调节方法（指导书原话）：调节电位器【SW1】，使得红外发射管【LEAS1】与红外接收管【RC1】距离障碍物小于 10cm 时，LED 灯【L1】亮起；否则【L1】灭。
- 开关量与电平约定：模块输出只有两种电平。本模块约定：正前方有障碍时绿灯亮起，OUT 引脚为低电平；反之为高电平（指导书 3 节原话）。也就是"检测到障碍=0、没检测到=1"。这个 0/1 约定是读懂本章主函数的钥匙，读反了会觉得每行注释都是错的。
- 开关量反馈控制：不测量具体距离数值，只判断"有/无"。好处是程序极简；代价是分档粗糙——指导书 3 节的"避障策略表"是策略示意，代码实际做不到"15–30cm 减速"，因为两路开关量给不出距离值。
- 回顾项：定时器 0 与软件 PWM 见实验二；六个运动函数见实验三；key_scan 见实验五。本章不再展开。

### 6.3 硬件与接线

本实验新增硬件是 2 路红外避障模块（两块相同的 IR-08H 小板），装在小车前部左右两侧（指导书 img_106 实车照片，红框标出安装位）。引脚映射：

| 信号名（代码） | 单片机引脚 | 扩展板丝印 | 接线头 | 作用 |
|---|---|---|---|---|
| AvoidSensorLeft | P1.6 | IN7 | J10 第 2 脚 OUT1 | 左侧避障模块输出 |
| AvoidSensorRight | P1.4 | IN5 | J9 第 2 脚 OUT1 | 右侧避障模块输出 |

接线头为 PH2.0 4P，四脚顺序为 VCC、OUT1（→IN5/IN7）、OUT2（→IN6/IN8，本实验不用）、GND。模块另有 LT（寻光输出）、HW（避障输出）与 GND 地、VCC 电源四线，板上指示灯：L1 避障灯、L2 寻光灯、L3 电源灯、S2 可测光源 AD 值（实验八用）。

接线注意两条（指导书"注"原文）：进行实验时，Arduino 功能跳线不需要插跳线帽（在 51 单片机上方）；两块模块各自调电位器，调到 10cm 内 L1 亮。

### 6.4 原理详解

主循环的判断逻辑是一个 4 分支真值表。设 L=LeftSensorValue、R=RightSensorValue（0=该侧检测到障碍）：

| L | R | 含义 | 动作 |
|---|---|---|---|
| 1 | 1 | 两侧都没检测到 | run() 前进 |
| 1 | 0 | 右侧检测到 | spin_left(2) 原地左转避开 |
| 0 | 1 | 左侧检测到 | spin_right(2) 原地右转避开 |
| 0 | 0 | 两侧都检测到（迎面正对） | spin_right(2) 固定方向脱困 |

为什么"右侧有障碍反而左转"？避障的原则是转向无障碍的一侧：右前有东西，车头往左摆就能绕开。两侧全堵时程序不区分场合，固定右转（spin_right(2)），配合主循环不断重测，先转到哪边空就往哪边走——这正是"开关量+固定动作"的简化决策。

时序上还要算一笔账：spin_left(2) 里的 2 经过 spin_left 函数内部的 delay(time * 100) 变成延时 200ms。0.2 秒够不够转出角度取决于电池电压与地面摩擦，这也是扩展实验里调节的对象。主循环每转完一次立刻重新读传感器，所以"转多少"实际由"转几次"累积而成，直到前方读数变回 1 才恢复前进。

指导书注意：正文写的避障策略表（>30cm 全速前进、15–30cm 减速、<15cm 停止判断、侧向 <20cm 避让）需要测距能力，本实验的红外开关量给不出距离分档，代码只实现了"有障碍就转"。策略表可理解为设计目标的分层描述，验收时能讲清这个差距是加分点。

### 6.5 代码逐段精讲

程序骨架与实验五完全同构：头文件、引脚定义、delay、PWM 输出函数、运动函数、timer0 中断、key_scan、main。以下按顺序讲，与实验三逐字相同的函数不再整段重复。

第一段，头文件与引脚定义（img_110 逐字转录）：

```c
#include "STC12C5A60S2.H"

//定义电机引脚
sbit Left_motor_go=P2^1;     //左电机前进AIN2
sbit Left_motor_back=P2^2;   //左电机后退AIN1
sbit Right_motor_go=P2^4;    //右电机前进BIN2
sbit Right_motor_back=P2^3;  //右电机后退BIN1
sbit Left_motor_pwm=P2^0;    //左电机控速PWMA
sbit Right_motor_pwm=P2^5;   //右电机控速PWMB

//红外避障引脚定义
sbit AvoidSensorLeft =  P1^6;  //定义左边避障的红外传感器引脚为IN7---P1.6
sbit AvoidSensorRight = P1^4;  //定义右边避障的红外传感器引脚为IN5---P1.4

//按键引脚定义
sbit key = P2^7;

unsigned char pwm_val_left  =0; //变量定义
unsigned char pwm_val_right =0;

//速度调节变量 0-20,0最小,20最大
unsigned char push_val_left =5; //左电机占空比push_val_left/20
unsigned char push_val_right=5; //右电机占空比push_val_right/20

bit Right_PWM_ON =1;            //右电机PWM开关
bit Left_PWM_ON  =1;            //左电机PWM开关

unsigned char LeftSensorValue ;  //定义变量来保存红外传感器采集的数据大小
unsigned char RightSensorValue ;
```

新增的只有两组：AvoidSensorLeft/Right 把 P1.6、P1.4 起了逻辑名；LeftSensorValue/RightSensorValue 是两个全局变量，用来暂存每次读到的引脚电平。sbit 定义的是"读引脚"还是"写引脚"，取决于电路方向——P1.6/P1.4 在这里是输入，读它就是拿模块输出。

第二段，delay、pwm_out_left_motor、pwm_out_right_motor、timer0：与实验二/三逐字相同（分别见 img_111、img_112、img_120 与实验二 5.2–5.4 节），机制不变——timer0 每 1ms 中断一次，按 push_val/20 的占空比输出 PWM。

第三段，运动函数（img_113–img_119）：run(void)、brake(time)、left(time)、right(time)、spin_left(time)、spin_right(time)、back(time) 七个函数与实验三逐字相同，运动姿态与代码对照见实验三 4.3 节。唯一要记住的差异点：本实验主循环调用的 run() 是无参版本（内部 push_val 固定 10，无延时），spin_left/spin_right 传的是"0.1 秒单位"的时间参数。

第四段，key_scan：与实验五逐字相同（三层判断消抖，见实验五 4.2 节），img_121 主函数烧录前先等一次按键。

第五段，主函数（img_121 逐字转录）：

```c
void main()
{
    P2=0XC0;    //关电机
    TMOD=0X01;  //定时器工作方式1
    TH0=0XFC;   //1ms定时，装入初值
    TL0=0X66;
    TR0=1;      //启动T0工作
    ET0=1;      //允许T0中断
    EA =1;      //开总中断

    //调用按键扫描函数
    key_scan();

    while(1)
    {
        //遇到障碍物,红外避障模块的指示灯亮,端口电平为0
        //未遇到障碍物,红外避障模块的指示灯灭,端口电平为1
        LeftSensorValue  = AvoidSensorLeft;
        RightSensorValue = AvoidSensorRight;

        if (LeftSensorValue == 1 && RightSensorValue == 1)
        {
            run();         //当两侧均未检测到障碍物时调用前进函数
        }
        else if (LeftSensorValue == 1 && RightSensorValue == 0)
        {
            spin_left(2);  //右边探测到有障碍物，有信号返回，原地向左转
        }
        else if (RightSensorValue == 1 && LeftSensorValue == 0)
        {
            spin_right(2); //左边探测到有障碍物，有信号返回，原地向右转
        }
        else
        {
            spin_right(2); //当两侧均检测到障碍物时调用固定方向的避障(原地右转)
        }
    }
    return;
}
```

逐块解释：初始化段与实验二/三相同（P2=0XC0 一次关电机并把按键脚拉高；TMOD=0X01 选定时器 0 方式 1；TH0:TL0=0XFC66 装 1ms 初值；TR0/ET0/EA 三级开关打开中断）。主循环第一步是"把引脚状态抄进变量"——LeftSensorValue = AvoidSensorLeft 执行的是一次读引脚操作，抄进变量后再判断，避免同一分支里引脚电平变化导致前后不一致。随后 4 分支与 6.4 节真值表一一对应。

两个细节值得点透。其一，spin_left(2) 的 2 是 0.1s 单位（函数内 delay(time*100)），所以每次原地转 0.2 秒；而注释里"有信号返回"指的是"检测到障碍物（输出 0）"的另一种说法，与条件里的 ==0 对应。其二，最后的 else 涵盖"两侧都=0"，此时注释明说"固定方向的避障(原地右转)"——开关量方案里没有更聪明的选择，转起来让传感器重新扫过环境，属于简单但有效的脱困策略。

### 6.6 实验操作步骤

1. 断电装模块：把两块红外避障板装到车头左右支架，确认探头朝前、略向外张开；按 6.3 表接好 J9/J10 排线（VCC-GND 方向不可接反）。
2. 电位器自检：不上电无法调，先给系统上电但不烧录运行程序——两块板的 L3 电源灯应亮；取白纸一张靠近任一模块 10cm 内，该模块 L1 亮、移开则灭；不达标的调 SW1 电位器重复测试。
3. 编译烧录：Keil 里确认源文件无语法错误，Build 出 0 Error；STC-ISP 选对型号与 COM 口，烧录开关拨 ON，拔掉蓝牙模块（若有），先点"下载/编程"再按板子电源开关，等待"操作成功"。
4. 运行观察：把车放地面空旷处，按启动键（key_scan 放行主循环），车应直行；用手掌或纸盒放到右前方 10cm 内，车应原地左转绕开；放到左前方则右转。
5. 结束：开关拨 OFF 断电，拆线还原。

### 6.8 难点与易错点

1. 电平约定读反。最典型误区：以为"检测到障碍"输出 1。实际是检测到=0（灯亮）。判断依据写反后，车会在空地上原地转、见了障碍反而直冲——改回约定即可，不必换硬件。
2. 环境光干扰。红外接收管对阳光、白炽灯中的红外成分敏感，强光下可能出现"明明没障碍却报障碍"。处理：调低灵敏度（旋转电位器），避开阳光直射，或缩短判定距离。
3. 两个模块互相干扰。左右两板探头相对或距离过近时，甲板发出的红外可能被乙板接收。处理：探头保持朝前张开的角度，不要左右对射。
4. 转角不合适。spin_left(2) 固定 0.2 秒，电池电压低时转角变小，可能反复蹭到障碍。处理：把 2 调大，或先充满电再验收。
5. 忘拔蓝牙/忘拨烧录开关。烧录失败的两大主因，见预备实验 6.3 节。

### 6.9 排错表

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 上电两模块电源灯不亮 | 排线 VCC/GND 接反或未插紧 | 断电核对 PH2.0 4P 线序 |
| 空旷处车原地转 | 电位器过灵敏或环境红外干扰 | 重调 SW1 到 10cm 阈值；避开强光 |
| 障碍贴近仍直行 | 电位器太迟钝、探头装反朝上 | 重调电位器；确认探头朝前 |
| 只会转向不会前进 | 左右传感器读数恒为 0（线序错或模块坏） | 逐个模块做 10cm 自检 |
| 烧录不进 | 烧录开关未拨 ON/蓝牙占用 RX TX/COM 选错 | 三项逐一检查 |
| 电机不转 | 电池电压过低（L1 灭）或 P2 未上电 | 充电；核对扩展板供电 |

### 6.10 扩展实验怎么做

指导书任务：控制小车通过红外避障逃离死角。思路：死角=两侧同时检测到障碍且持续一段时间。可在主循环的 else 分支里加计数或计时，连续 N 次"两侧都=0"时执行一组更大的动作（比如先 back(5) 后退 0.5 秒，再大幅 spin_right(10)），打破对称。关键改动点：else 分支、spin 参数、必要时利用 back 函数。进一步可让左右转随机交替，避免在 U 形死角里来回撞。

### 6.11 小结与衔接

本实验把"读引脚→查条件→调动作"的闭环立起来了，代价是决策粒度只有"有/无"。下一个实验（红外跟随）用完全相同的硬件把逻辑反过来——从"躲开反射源"变成"追上反射源"，对比两份主函数的 4 个分支，是理解"算法决定行为"最直观的一课。

## 实验七 红外跟随实验

### 7.1 实验定位

实验七与实验六共用同一种硬件（两路红外反射模块、同样的 P1.6/P1.4 引脚），只把决策逻辑从"避让反射源"改成"追上反射源"。指导书目标：哪一个方向有障碍物（跟随者）则跟随哪个方向行走。它的价值在于对比学习：同一套感知，换一个真值表就换一种"性格"，这是行为设计最朴素的形式。

### 7.2 预备知识

新概念只有"跟随逻辑"本身；传感器原理、电平约定（检测到=0）、阈值调节全部见实验六 6.2 节，不再重复。跟随模式下"检测到=0"的含义变成了"这一侧有我的目标（人/物）"，因此：两侧都检测到=目标在正前方，前进；只有一侧检测到=目标在侧前方，向那一侧转；两侧都检测不到=目标丢失，停下等它出现。

### 7.3 硬件与接线

与实验六完全一致（引脚映射表见 6.3 节），代码里引脚的逻辑名换成 FollowSensorLeft/FollowSensorRight，对应的物理引脚仍是 P1.6（IN7，左）、P1.4（IN5，右）。模块状态指示灯示意图、Arduino 跳线不插的提醒、电位器 10cm 调节法均同实验六（指导书注："模块状态指示灯示意图可以参考实验六"）。

### 7.4 原理详解

主循环 4 分支真值表（0=该侧检测到跟随者）：

| L | R | 含义 | 动作 |
|---|---|---|---|
| 0 | 0 | 目标在正前方 | run() 前进 |
| 0 | 1 | 目标在左前方 | spin_left(2) 原地左转追 |
| 1 | 0 | 目标在右前方 | spin_right(2) 原地右转追 |
| 1 | 1 | 目标丢失 | brake(0) 停止 |

与实验六逐行对照：run 和 spin_left/spin_right 的触发条件完全对调（实验六是 1/1 才 run，这里是 0/0 才 run），兜底分支从"固定方向转"换成 brake(0)——brake(0) 经函数内 delay(0) 实际是"立即停止、零延时"，丢失目标就刹车待命。

跟得紧不紧取决于两个阈值：电位器决定的探测距离（约 10cm 量级）与每次转向的角度（0.2 秒）。目标走近到两路都亮时车还在前进，容易碰脚——这是开关量跟随的固有局限，扩展实验的"定距跟随"就是针对它提出的改进方向。

第二处差异，主函数（img_137 逐字转录）：

```c

{
    P2=0XC0;    //关电机
    TMOD=0X01;  //定时器工作方式1
    TH0=0XFC;   //1ms定时，装入初值
    TL0=0X66;

        }
```

4. 安全提醒：车会朝人走，穿封闭鞋，别让它压脚；测试场地清空。

### 7.8 难点与易错点

1. 把跟随与避障的 0/1 读反。两实验条件互为镜像，背结论不如记约定：0=该侧有反射目标。分不清时看模块指示灯——灯亮=该侧检测到。
2. 车碰到跟随者。探测距离阈值远小于人的脚到探头的最短距离时，两路常亮，车一路前进直到接触。处理：把电位器阈值调小（更近才触发），或扩展实验里引入测距。
3. 目标丢失后猛转。若把兜底分支改成转动而非 brake(0)，目标丢失时车会一直旋转，人回来时车可能正背对——本实验代码用 brake(0) 正是避免这一点。
4. 环境干扰同实验六：强红外背景光、两板对射都会造成误判，处理方法见 6.8 节第 2、3 条。
5. 烧录失败三查：烧录开关、蓝牙占用、COM 口（见预备实验 6.3 节）。

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 人在正前方车反而停 | 电平约定理解反了或线序接错 | 按指示灯核对 0/1 约定；查 J9/J10 线序 |
| 车不动也不转 | 电池低压（L1 灭）或未按键 | 充电；上电后按启动键 |

### 7.10 扩展实验怎么做

指导书任务：控制小车通过红外传感器测距实现定距跟随。先明确一个现实约束：两路开关量红外只有"有无"没有"距离"，定距跟随必须引入能测距的器件。可行路线两条：其一，换模拟量输出的红外测距器件（模块 S2 引脚标注"可测光源 AD 值"，说明该系列硬件预留了模拟量通道，配合单片机 AD 采集可做距离分档——此为方向性提示，指导书未给本车的 AD 例程）；其二，用实验十的超声波测距承担"定距"，红外只做左右定位，两传感器融合。核心改动点：主循环里把 0/1 判断升级为"距离区间 + 左右开关"的二维判断，前进/停止由距离区间决定，左右由红外决定。

### 7.11 小结与衔接

同一套硬件，一个真值表之差，小车从"躲人"变成"追人"。至此两路开关量的可能性已经穷尽：再往上加智能，需要能输出数值的传感器。实验八先用光敏电阻把"检测对象"从红外换成可见光，实验九把两路扩成四路做巡线状态机，实验十则正式进入数值测距。

## 实验八 寻光行走实验

### 8.1 实验定位

实验八把感知对象从红外反射换成环境光：车追着光走——两路都有光前进，只有左边有光向左转，只有右边有光向右转，都没光就停。指导书把它列为创新实验之一，与"智能追光"玩法（扩展板宣传图之一）对应。对读者的意义：证明"读引脚→查条件→调动作"框架对任意开关量传感器都成立，同时第一次接触光敏电阻这种"电阻值随物理量变化"的器件。

### 8.2 预备知识

- 光敏电阻与光电导效应：指导书原话——光敏电阻器是利用半导体的光电导效应制成的一种电阻值随入射光强弱而改变的电阻器，又称光电导探测器；入射光强，电阻减小，入射光弱，电阻增大。电阻变化本身不能被单片机直接读，需要电路把它变成电平：寻光模块内部用光敏电阻与其他电阻分压，再经比较器输出开关量。
- 本模块的电平约定（与避障模块相反，务必注意）：遇到光线，寻光模块的指示灯灭，端口电平为 1；未遇光线，指示灯亮，端口电平为 0（指导书 img_154 主函数注释原话）。即"有光=1、无光=0"。
- 灵敏度电位器调节（指导书原话）：调节该模块的电位器【SW1】，使得正常室内光照下 LED 灯【L2】亮，当手电筒的灯光照射在光敏电阻【K1】上时，LED 灯【L2】灭。注意这条标定与避障模块（10cm 内 L1 亮）的方向相反，别调混。
- 回顾项：红外反射原理见实验六；运动函数与 key_scan 见实验三、实验五。

### 8.3 硬件与接线

新增硬件是两路寻光模块（与避障模块同系列板，板上光敏电阻、L2 寻光灯、S2 测光源 AD 值焊点）。引脚映射（img_143 逐字）：

| 信号名（代码） | 单片机引脚 | 扩展板丝印 | 作用 |
|---|---|---|---|
| LdrSensorLeft | P1.7 | IN8 | 左侧光敏电阻模块输出 |
| LdrSensorRight | P1.5 | IN6 | 右侧光敏电阻模块输出 |

接线头同样是 J9/J10（PH2.0 4P：VCC、OUT1→IN5/IN7、OUT2→IN6/IN8、GND），左右模块分别插到对应插座。安装位置同避障模块，光敏电阻面朝前上方，便于接收手电筒光源。

指导书注意：img_143 中"//寻光引脚定义"的注释行在代码里出现了两次（第二处下方才是 sbit key），系排版重复；更关键的是主函数用到的 LdrSensorLeftValue、LdrSensorRightValue 在该定义图里没有声明，自己拼装完整程序时需补一行 unsigned char LdrSensorLeftValue, LdrSensorRightValue;，否则编译报"undefined identifier"。

### 8.4 原理详解

主循环 4 分支真值表（1=该侧有光）：

| 左值 | 右值 | 含义 | 动作 |
|---|---|---|---|
| 1 | 1 | 两侧都有光（光源在正前方且较宽） | run() 前进 |
| 1 | 0 | 只有左侧有光 | left() 向左转 |
| 0 | 1 | 只有右侧有光 | right() 向右转 |
| 0 | 0 | 无光 | brake(0) 停止 |

与实验七对照，结构完全一样，变化有三处：条件值反转（1 才是有"目标"）、左右分支的动作从原地转 spin 换成单轮驱动的 left()/right()（转弯半径大、动作温和，追光不需要原地急转）、兜底从 brake(0) 同样是停止但条件是无光。

物理过程的因果链值得走一遍：手电筒从左侧照来→左侧光敏电阻受光强、阻值减小→分压点电压变化→模块比较器翻转、L2 灭、OUT 输出 1→P1.7 读到 1→主循环进入 left() 分支→左轮停、右轮转→车头向左偏→左侧继续受光、右侧逐渐也受光→两路都为 1→前进。理解这条链，就理解了"追光"为什么天然收敛到光源方向。

主函数（img_154 逐字转录）：

```c
void main()
{
    P2=0XC0;    //关电机
    TMOD=0X01;  //定时器工作方式1
    TH0=0XFC;   //1ms定时，装入初值
    TL0=0X66;
    TR0=1;      //启动T0工作
    ET0=1;      //允许T0中断
    EA =1;      //开总中断

    //调用按键扫描函数
    key_scan();

    while(1)
    {
        //遇到光线,寻光模块的指示灯灭,端口电平为1
        //未遇光线,寻光模块的指示灯亮,端口电平为0
        LdrSensorRightValue = LdrSensorRight;
        LdrSensorLeftValue  = LdrSensorLeft;

        if (LdrSensorLeftValue == 1 && LdrSensorRightValue == 1)
        {
            run();   //两侧均有光时信号为1，光敏电阻指示灯灭,小车前进
        }
        else if (LdrSensorLeftValue == 1 && LdrSensorRightValue == 0)
        {
            left();  //左边探测到有光，有信号返回，向左转
        }
        else if (LdrSensorRightValue == 1 && LdrSensorLeftValue == 0)
        {
            right(); //右边探测到有光，有信号返回，向右转
        }
        else
        {
            brake(0);//均无光，停止
        }
    }
    return;
}
```

指导书注意：left(); 与 right(); 是无参调用，而本实验（img_148/149）定义的 left(time)、right(time) 带 unsigned int 参数、内部执行 delay(time*100)。照此抄写，Keil 编译会报参数不匹配的错误（或带告警把随机值传进去），属于指导书排版笔误。实际操作两种改法：给参数（如 left(1) 表示转 0.1 秒，最接近原意）；或把 main 里改成固定小角度的 spin。验收答辩能指出并修正这一处，是"读懂代码"的直接证据。

### 8.8 难点与易错点

1. "有光=1"与避障"有障碍=0"相反。三个实验三种约定（避障 0、跟随 0、寻光 1），靠背容易混；唯一可靠的办法是每块板上电后用光/手扫一遍，看灯与引脚值的对应。
2. left()/right() 无参调用的编译错误（见 8.5 指导书注意）。报错信息通常是 error C212 之类参数相关提示；定位到 main 里两行补参数即可。
3. LdrSensorLeftValue/RightValue 未声明（见 8.3 指导书注意）。报 undefined identifier；在全局区补声明。
4. 室内光饱和。白天整个房间亮度超过阈值时，两路恒为 1，车只会直行不会转向。处理：拉窗帘制造明暗差，或调高电位器阈值。
5. 光源太远/太弱。光敏电阻对小手电在 1m 外基本无反应，属于器件灵敏度现实，引导距离控制在几十厘米内。
6. 左右方向感错乱：光敏电阻装反或接线对调，见实验七排错表同款处理。

### 8.10 扩展实验怎么做

指导书任务：试验不同强度、不同方向的光照对小车跟随效果的影响。建议做成一张变量-现象记录表：光源强度档（强手电/弱手电/手机灯）、距离档（20/40/80cm）、方向档（正前/左 30°/左 60°/侧后方），每格记录"车的反应（直行/转向/停）与转向修正次数"。能预期的规律：强度越弱或距离越远，越容易跌出阈值（表现为该侧"无光"）；方向越偏，单侧触发时间越长，转向次数越多。这份表直接可用于实验报告的"实验数据记录与图表分析"栏（报告占分 25%，见"收尾篇"第 2 节）。

### 8.11 小结与衔接

实验六、七、八共用同一主循环骨架，只换了传感器和真值表——这三章合起来就是"开关量反馈控制"的完整教学单元。下一个实验九把两路红外扩成四路，判断从"某侧有没有"升级为"哪一路压线"，主循环第一次出现真正的状态机味道；再往后实验十引入定时器测脉宽，反馈量从电平变成数值。

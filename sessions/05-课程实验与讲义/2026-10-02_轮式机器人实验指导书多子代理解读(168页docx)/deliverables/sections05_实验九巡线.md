# 实验九（巡线实验）

实验九是基础创新两段之间的桥梁，也是课程验收的重头：第六章评分标准里"完整走完标准 S 形赛道"独占 60 分。技术上它是实验六七八那套"读引脚→查条件→调动作"框架的加强版——传感器从 2 路扩到 4 路，判断从"有没有"升级为"哪一路压线"，运动函数第一次带独立的速度参数。看懂本章，后两个超声波实验的代码反而显得简单。

## 9.1 实验定位

指导书给出的目标分三层：基础功能是机器人沿黑色引导线自主行走；进阶功能是过交叉线、识别直角转弯、速度可调；创新点是自适应速度、路径记忆、多机器人协作。对应的考核标准（指导书原文）：完整走完标准 S 形赛道（60 分）、行走速度与稳定性（20 分）、过交叉线与直角弯能力（10 分）、创新功能实现（10 分）。

练的能力：多传感器状态机设计；根据误差大小分级纠正的控制思想（最外路压线用更大速度纠正）；以及全书最需要耐心的环节——四个电位器的逐路标定。

## 9.2 预备知识

- 红外反射巡线的物理基础：指导书原话——红外线发射到黑线上会被黑线吸收掉，发射到其他颜色的材料上会反射到红外接收管上。所以"压线"与"压白"的区别就是接收管收不收得到反射光。
- 电平约定（主循环注释原话）：检测到黑线时循迹模块相应的指示灯亮，端口电平为 0；未检测到黑线时指示灯灭，端口电平为 1。注意这条与实验六避障的约定一致（检测到=0），与实验八寻光（有光=1）相反。理解上的自洽点：都是"接收管有信号输出"决定 0/1，黑线吸光导致接收弱，模块比较器输出 0。
- 4 路布局与"位置编码"：4 个探头横排（指导书设计思路建议间距 1–2cm），压线路况由 4 个 0/1 组成的状态表达。中间两路压线=居中；左内压线=车体略偏右需要左修；最外路压线=严重偏离或遇到直角/锐角；全部为 1=车在黑线之外（丢线或空档）。
- 带速度参数的运动函数：实验九的 run/left/right/spin_left/spin_right 首次把左右轮占空比作为参数传入（0–20 刻度），为"分级纠正"提供手段。占空比=速度值/20，如 run(12,12) 即左右轮都是 60% 占空比。
- 回顾项：软件 PWM 与定时器 0 见实验二；key_scan 见实验五。

## 9.3 硬件与接线

新增硬件是 4 路红外巡线模块（亚博智能 Tracking Sensor BST-02 V1.0，一排 4 个蓝色红外探头）。引脚定义（img_160 逐字转录）：

```c
//循迹红外引脚定义
// TrackSensorLeftPin1 TrackSensorLeftPin2 TrackSensorRightPin1 TrackSensorRightPin2
//      P1.1                P1.0                 P1.2                     P1.3
sbit TrackSensorLeftPin1  = P1^1;  //定义左边第一个循迹红外传感器引脚为P1.1
sbit TrackSensorLeftPin2  = P1^0;  //定义左边第二个循迹红外传感器引脚为P1.0
sbit TrackSensorRightPin1 = P1^2;  //定义右边第一个循迹红外传感器引脚为P1.2
sbit TrackSensorRightPin2 = P1^3;  //定义右边第二个循迹红外传感器引脚为P1.3
```

对照表的读法：从左到右 4 路探头的逻辑名依次是 LeftPin1、LeftPin2、RightPin1、RightPin2，对应 P1.1、P1.0、P1.2、P1.3——注意左右两半的编号顺序不连续（左半边是 P1.1 在最外、P1.0 靠内），这是驱动库沿用的命名，接线时以模块板上的丝印和扩展板 IN1–IN4 的对应关系为准（循迹模块接口 J8 为 PH2.0 6P：VCC、X1→IN1(P1.0)、X2→IN2(P1.1)、X3→IN3(P1.2)、X4→IN4(P1.3)、GND）。装好后先跑一次自检（见 9.6 节），若发现方向镜像，对调 sbit 定义即可。

```c
//定义各个循迹红外引脚采集的数据的变量
unsigned char TrackSensorLeftValue1;
unsigned char TrackSensorRightValue1;

//速度调节变量 0-20,0最小,20最大

bit Right_PWM_ON=1;              //右电机PWM开关
bit Left_PWM_ON =1;              //左电机PWM开关
```

电位器标定（指导书调试方法原文，四路逐个做）：调节电位器【SW1】，使得光电传感器【P1】对着白色底面时，LED 灯【L1】灭，对着黑线底面时，LED 灯【L1】亮；SW2/SW3/SW4 对 P2/L2、P3/L3、P4/L4 同理。四路必须分别标定，任何一路反了，状态机就会把"压线"读成"丢线"。

指导书注意：设计思路一节建议"传感器横向布置，间距 1–2cm"，而模块成品 4 探头的间距是固定的，调整手段是探头离地高度（越低越灵敏、探测点越窄）；"间距 1–2cm"可理解为设计参考而非要求改硬件。

## 9.4 原理详解

### 9.4.1 七种工况与状态编码

指导书 img_157 状态分析图给出了七种典型工况，图中红色空心圆表示探头压在黑线上（读 0）、黄色实心圆表示压在白底（读 1）。按代码条件整理：

| 工况 | 典型状态（左1 左2 右1 右2） | 代码分支 | 动作 |
|---|---|---|---|
| 前进（居中） | 1 0 0 1 | 中间两路压线 | run(12,12) 直行 |
| 左小弯 | 1 0 1 1 | 左内压线 | left(0,10) 左轮停右轮转 |
| 右小弯 | 1 1 0 1 | 右内压线 | right(10,0) 左轮转右轮停 |
| 最左压线 | 0 1 1 1 | 左外侧压线 | spin_left(11,11) |
| 最右压线 | 1 1 1 0 | 右外侧压线 | spin_right(11,11) |
| 左直角/左锐角 | 0 X 0/0 组合（左外侧与右侧同时压线） | 见主循环第一个分支 | spin_left(12,12)+delay(80) |
| 右直角/右锐角 | 左侧任一与右2同时压线 | 见主循环第二个分支 | spin_right(12,12)+delay(80) |
| 丢线/空档 | 1 1 1 1 | 无分支命中 | 保持上一动作 |

控制思想是"误差越大、纠正越猛"：居中时两侧同速直行；单侧内路压线说明只偏了一点，用"一侧停一侧走"的温和差速（速度值 10/20）；最外路压线说明偏得多，用原地转（速度 11）直接修正方向；直角与锐角是最严重的偏差，用原地转（速度 12）加固定 80ms 延时，强制转过一个大角度。这一层"分级响应"正是第二章 PID 里"比例思想"的开关量雏形，报告里可以对照展开。

{{IMG:img_157.png|巡线传感器状态分析：红色空心圆=压在黑线（读 0），黄色实心圆=压在白底（读 1），七种工况对应的车道与探头状态}}

### 9.4.2 为什么直角要加 delay(80)

spin_right(12,12) 本身不带延时（本实验的 spin_right 是"设定两轮反转/正转"就返回），需要显式 delay(80) 让它转够时间——80ms 的原地转在 60% 占空比下大约修正一个固定角度，足以让车头甩过直角。delay(80) 的单位是毫秒（delay 函数直接以 xms 计），不要与运动函数内 delay(time*100) 的 0.1 秒刻度混淆。

指导书注意：主循环注释写"以上 6 种电平状态时小车原地右转，速度为 20，延时 80ms"，但对应代码是 spin_right(12,12)——注释的"速度为 20"与代码速度值 12 不一致，以代码为准（12/20=60% 占空比）。

### 9.4.3 丢线保持：1 1 1 1 时的隐含行为

主循环 8 个 if/else if 分支全部落空时（四路全 1，例如过交叉空档、线很宽的拐点瞬间、或车被提起），没有任何 else 兜底——程序不改变 push_val_left/right 与方向引脚，电机保持上一个动作继续执行。这就是注释"当为 1 1 1 1 时小车保持上一个小车运行状态"的实现方式：不写代码本身就是设计。副作用也要知道：如果丢线前的最后动作是高速原地转，车会一直转下去直到某一路重新压线——这正是"丢线找回"扩展的切入点。

## 9.5 代码逐段精讲

### 9.5.1 带速度参数的运动函数

本实验的运动函数与实验三版本的区别只有一处：push_val 不再写死 10，而是由参数传入。以 run 和 spin_right 为例（指导书代码逐字）：

```c
void run(int left_speed, int right_speed)
{
    //左电机前进
    Left_motor_go = 1;   //左电机前进使能
    Left_motor_back = 0; //左电机后退禁止
    //更新指定管脚的PWM值，更改可实现控速（0-20）
    push_val_left=left_speed;
    //右电机前进
    Right_motor_go=1;   //右电机前进使能
    Right_motor_back=0; //右电机后退禁止
    //更新指定管脚的PWM值，更改可实现控速（0-20）
    push_val_right=right_speed;
    return;
}

void spin_right(int left_speed, int right_speed)
{
    //左电机前进
    Left_motor_go = 1;   //左电机前进使能
    Left_motor_back = 0; //左电机后退禁止
    //更新指定管脚的PWM值，更改可实现控速（0-20）
    push_val_left=left_speed;
    //右电机后退
    Right_motor_go=0;    //右电机前进禁止
    Right_motor_back=1;  //右电机后退使能
    //更新指定管脚的PWM值，更改可实现控速（0-20）
    push_val_right=right_speed;
    return;
}
```

left(left_speed, right_speed) 为"左停右转"，right 为"左转右停"，spin_left 为"左退右进"，与实验三姿态一致；brake(time)（img_163）与 back(time)（img_164）同实验三。这一组函数是"速度可调"进阶功能的物质基础——想调速，改调用处的参数即可，不用动函数体。

### 9.5.2 主循环状态机

主函数（指导书代码逐字，注释完整保留）：

```c
void main()
{
    //由于这三个引脚默认高电平会导致点亮探照灯，所以程序中将引脚置低电平
    //设置P4口作为普通的IO口使用
    P4SW |= (1<<4);
    P4SW |= (1<<5);
    P4SW |= (1<<6);
    //设置P4口为强推挽输出模式
    P4M1 &= ~(1<<4);
    P4M1 &= ~(1<<5);
    P4M1 &= ~(1<<6);
    P4M0 |= (1<<4);
    P4M0 |= (1<<5);
    P4M0 |= (1<<6);
    LED_R=0;
    LED_G=0;
    LED_B=0;
    P2=0XC0;    //关电机
    TMOD=0X01;  //定时器工作方式1
    TH0=0XFC;   //1ms定时，装入初值
    TL0=0X66;
    TR0=1;//启动T0工作
    ET0=1;//允许T0中断
    EA =1;    //开总中断
    //调用按键扫描函数
    key_scan();
    while(1)
    {
        //检测到黑线时循迹模块相应的指示灯亮，端口电平为0
        //未检测到黑线时循迹模块相应的指示灯灭，端口电平为1
        TrackSensorLeftValue1  = TrackSensorLeftPin1;
        TrackSensorLeftValue2  = TrackSensorLeftPin2;
        TrackSensorRightValue1 = TrackSensorRightPin1;
        TrackSensorRightValue2 = TrackSensorRightPin2;

        //四路循迹引脚电平状态
        // 0 0 X 0
        // 1 0 X 0
        // 0 1 X 0
        //以上6种电平状态时小车原地右转，速度为20,延时80ms
        //处理右锐角和右直角的转动
        if ( (TrackSensorLeftValue1 == 0 || TrackSensorLeftValue2 == 0) &&  TrackSensorRightValue2 == 0)
        {
            spin_right(12, 12);
            delay(80);
        }
        //四路循迹引脚电平状态
        // 0 X 0 0
        // 0 X 0 1
        // 0 X 1 0
        //处理左锐角和左直角的转动
        else if ( TrackSensorLeftValue1 == 0 && (TrackSensorRightValue1 == 0 ||  TrackSensorRightValue2 == 0))
        {
            spin_left(12, 12);
            delay(80);
        }
        // 0 X X X
        //最左边检测到
        else if ( TrackSensorLeftValue1 == 0)
        {
            spin_left(11, 11);
            //delay(10);
        }
        // X X X 0
        //最右边检测到
        else if ( TrackSensorRightValue2 == 0 )
        {
            spin_right(11, 11);
            //delay(10);
        }
        //四路循迹引脚电平状态
        // X 0 1 X
        //处理左小弯
        else if ( TrackSensorLeftValue2 == 0 && TrackSensorRightValue1 == 1)
        {
            left(0, 10);
        }
        //四路循迹引脚电平状态
        // X 1 0 X
        //处理右小弯
        else if (TrackSensorLeftValue2 == 1 && TrackSensorRightValue1 == 0)
        {
            right(10, 0);
        }
        //四路循迹引脚电平状态
        // X 0 0 X
        //处理直线
        else if (TrackSensorLeftValue2 == 0 && TrackSensorRightValue1 == 0)
        {
            run(12, 12);
        }
        //当为1 1 1 1时小车保持上一个小车运行状态
    }
    return;
}
```

初始化段先配置 P4 口（关探照灯，见实验一 5.4 节对 P4SW/P4M0/P4M1 的完整解释），再关电机、配定时器 0、开中断、等按键——这套开场与实验六完全相同，不再逐行展开。

主循环是本章的全部难点，按优先级从高到低读：

1. 第一对分支处理直角与锐角。条件 (左1==0 或 左2==0) 且 右2==0 时 spin_right：直观含义是"黑线同时出现在左半边和最右边"——只有直角、锐角这类线体横向扫过的工况才会让相距最远的两路同时压线，属于最严重的状态，所以用最大速度 12 原地转并强制 80ms。对称的左转分支同理。
2. 第二对分支处理"只有最外侧一路压线"：spin_left(11,11)/spin_right(11,11)，无显式延时——转一下立刻重新读传感器，直到最外路脱离黑线，属于连续小步修正。
3. 第三对分支处理小弯：left(0,10)/right(10,0)——一侧轮子停、另一侧 50% 前进，画小弧跟线。
4. 直线分支 run(12,12)，60% 占空比直行。
5. 1 1 1 1 全白时无分支命中，保持上一状态（见 9.4.3 节）。

顺序不能随意调换：把直线分支放在最前，直角工况永远轮不到（因为直角时中间两路也可能压线，会先命中直线分支直冲出去）。if/else if 的排列本身就是控制策略。

数字走查两笔：run(12,12) 的 12 表示 12/20=60% 占空比，在 timer0 每 1ms 中断的软件 PWM 下，输出周期 20ms、高电平 12ms；delay(80) 为 80ms。spin_right(12,12)+delay(80) 合起来是"以 60% 占空比原地转 80ms"。

## 9.6 实验操作步骤

1. 铺赛道：用黑胶带或黑色电工胶带在白底面（KT 板、白色地板）贴 S 形标准赛道，线宽略宽于探头间距，弯道半径不要太小（先做缓弯，直角弯留到功能稳定后再加）。
2. 装模块：巡线板装车头前缘下方，探头朝地、离地高度以 1cm 左右为起点试（指导书未给定值，按灵敏度实测调整）。
3. 四路标定（9.3 节方法）：每路分别在白底与黑线上按"白灭黑亮"校准，四路全过才算标定完成。这一步花多少时间都值——巡线实验八成的问题出在标定。
4. 静态自检：上电前把车放在赛道上推一推，观察 4 个 L 灯在进出黑线时逐个亮灭，确认左右方向与代码命名一致。
5. 编译烧录：流程同前（烧录开关 ON、拔蓝牙、先点下载再开电源）。
6. 低速试跑：可先把主循环里所有速度值减半（如 12→6）试跑，确认逻辑无误后再提速。
7. 正式跑：按启动键放下车，人跟在车侧防冲出；直角弯脱线时及时拿车，防轮子空转缠线。
8. 结束断电还原。

## 9.8 难点与易错点

1. 标定不过关就上场。任何一路"白底也亮"或"黑线不亮"，状态机整体失真。表现五花八门（画龙、原地转、冲出弯道），根因排查永远从四路标定开始。
2. 左右镜像。若装车方向导致实际最左探头接成了 RightPin，车会在每个弯道上反向修正、加速脱线。处理：按 9.3 节对调 sbit 或对调接线。
3. 速度过快导致弯道甩出。60% 占空比在电池满电时可能偏快。处理：整体降速试跑，或把直行与小弯的速度值分开调（直行 12、小弯 8）。
4. delay(80) 与运动函数延时刻度混淆。本实验 spin 不自带延时，必须显式 delay；而 delay(80) 是 80ms。写成 delay(80) 与 spin_right(12) 配套、又误以为 spin 自带 80×100ms，会得出"转十来秒"的错误预期。
5. 探头离地过高。探测光斑变大、相邻两路同时压线，直角分支误触发频繁。处理：降低安装高度。
6. 直角分支误触发。宽黑线或交叉线上最外路与内侧同压时按直角处理属设计内行为；若在普通缓弯上频繁触发，多半是线太宽或探头太低。

## 9.9 排错表

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 车不走 | 电池低压/未按键/电机口未接 | 充电；上电后按启动键；查电机接线 |
| 直线上画龙 | 标定临界、直行速度偏快、左右轮速不均 | 重标四路；降速；交换左右轮电机插头对比 |
| 弯道冲出 | 速度过快/探头过高/弯道半径过小 | 降速；降低探头；加大弯道半径重贴 |
| 遇直角直冲 | 直角分支未命中（镜像或标定反） | 复查左右映射与"白灭黑亮" |
| 原地打转不停 | 丢线保持+起始位置全白 | 启动时把车放上黑线（中间两路压线）再按键 |
| 某路永远读 1 | 该路 LED 坏/电位器漂移/排线断针 | 单独标定该路，必要时换模块 |
| 转向迟钝 | 占空比低、电池电压低 | 提高速度参数；充满电 |
| 烧录不进 | 烧录开关/蓝牙/COM | 见预备实验 6.3 节 |

## 9.10 扩展与考核怎么做

指导书"设计思路"列出的三个进阶点，逐个给实现路径：

- 过交叉线：交叉时会出现两路以上的对称压线组合，现有直角分支会先转后走，多数情况能自行通过；若卡死，可在直角分支前加"交叉识别"（如四路全 0 或对称三路压线时直行通过一次）。
- 识别直角转弯：现有实现已含直角处理，可做的是把 80ms 调成可变参数，按电池电压实测标定转角。
- 速度可调：主循环已全部参数化，把各分支速度值提成宏或变量即可；按键加减档是最简单的交互方案（key_scan 改造，见实验五）。

创新点（自适应速度、路径记忆、多机器人协作）属于加分项：自适应速度可用"偏离程度决定速度"（误差大降速、居中提速）——把开关量判断改成计分式，是通向 PID 的台阶；路径记忆需要记录转向序列回放，工程量较大，报告里写清方案设计即可拿到"有深度思考"的分。

考核（60+20+10+10）的精力分配建议：先把 S 形赛道稳定跑满（这是 60+20 的基本盘），再练直角（10 分），最后才投入创新（10 分）；一份包含数据表（各速度档过弯表现）与"指导书注意"类勘误讨论的报告，对 25% 权重的"实验结果与数据分析"栏直接有效。

## 9.11 思考题参考

指导书本章未列思考题，但验收常问两问，给出参考答案。其一，"为什么中间两路压线是直行、最外路压线要原地转"——差动驱动里转向修正量必须与偏差量匹配（第二章运动学与 4.3 节比例思想），最外路压线代表偏差已跨过内侧探头的量程，小差速来不及拉回，必须用大角速度。其二，"1 1 1 1 为什么保持原状态"——丢线瞬间无法判断该往哪边找线，保持最后动作利用惯性咬回线上的概率大于任何固定方向的猜测；若要更稳，可在保持分支里加"丢线超时则刹车"的保护。

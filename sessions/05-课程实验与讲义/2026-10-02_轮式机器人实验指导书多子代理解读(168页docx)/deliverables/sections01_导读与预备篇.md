## 1 这本指导书怎么用

先看课程定位。指导书封面表格写明：课程类型是创新实践实验，适用专业为工学院各个专业（农业机械化及其自动化、农业工程、车辆工程、机械设计制造及其自动化、工业设计、机械电子工程、某工科专业等），实验学时 32 学时，实验性质为综合性、设计性实验。"综合性"意味着一个实验里同时有机械、电路、程序三种东西；"设计性"意味着验收时不止看"跑起来没有"，还要看你自己改了什么。

全书的主线是一台四驱智能小车，共 11 个实验，分成三个台阶：

| 阶段 | 实验 | 练的能力 | 关键器件 |
|---|---|---|---|

使用方法建议：每个实验都对照三份材料看——指导书原文（有原理图和代码截图）、本详解（逐行解释和推导）、手上的实物（接线以丝印为准）。指导书正文有少量笔误和口径不一致的地方，本详解在对应位置用"指导书注意"标出，动手前先把当章的"指导书注意"过一遍，能省掉大量排错时间。

### 3.3 扩展板使用说明里容易忽略的 6 件事

扩展板说明书页（图 1.4 附近的两张接线说明图）给出了一组极易被跳过、却直接影响成败的要点：

### 3.4 供电与安全

指导书 3.3.2 用加粗表格强调：接线前务必断开电源，接线完成后仔细检查、确认无误后再通电。原因在第 7 章安全规范里也写了——正负极接反会烧毁芯片和电机。操作顺序固定为：先摆好车、接好线、自查一遍线序与正负，最后才插电池、开开关。实验结束断开电源，把开关拨到 OFF 档，系统在不使用时没有消耗电能，电池可以用得更久（指导书预备实验第 4 步原话），再拆卸串口线还原。

## 4 第二章理论基础逐条讲透

指导书第二章列了三块理论：运动学、控制、传感器。这一节把它们全部落到"这台小车"上讲。

### 4.1 差动驱动：小车怎么转弯

这台车四个轮子都在驱动，但左右两侧各由同一路 PWM 控制（实验二起你会看到 push_val_left/push_val_right 各管一侧），所以整车仍按"左右两列轮子"分析，这就是差动驱动（Differential Drive）。指导书 2.1.1 列出三种典型运动：

- 直线运动：左右两轮转速相同；
- 原地旋转：左右两轮转速大小相等、方向相反；
- 圆弧运动：左右两轮存在转速差，机器人绕瞬时中心做圆周运动。

理解的关键是"转速差决定转向、方向组合决定姿态"：左右同向同速=直行；左右同速但一侧反转=原地转（车头画出一个小圆，圆心在两轴中点连线上）；一侧快一侧慢=向慢的那一侧偏转。对照后面实验三的六个函数就是：run（两轮同正转）、back（两轮同反转）、left（左停右转，向左拐小弯）、right（右停左转）、spin_left（左退右进，原地左转）、spin_right（左进右退，原地右转）。

指导书 2.1.2 给出运动学模型：线速度 v = (vR + vL) / 2，角速度 ω = (vR − vL) / L，其中 L 为两轮之间的轴距。两式的来历可以用"两轮各走一段弧"来推：设一个极短的时间 t，左右轮各前进 sR = vR·t 和 sL = vL·t，车体绕某个瞬时中心转过一个角度 θ。车体中心走过的距离是左右轮走过的平均（中心在两轮中点连线上，线速度取平均），所以 v = (vR + vL)/2；而车体转过的角度 θ 等于左右轮走过的弧长差除以轴距（一侧多走、一侧少走，差值摊在轴距 L 上就是转角），θ = (sR − sL)/L，两边同除 t 得 ω = (vR − vL)/L。

算例（假设性数字，仅帮助理解；指导书未给本车轴距，此处设 L = 15cm）：vR = 0.2 m/s、vL = 0.1 m/s，则 v = 0.15 m/s，ω = (0.2 − 0.1)/0.15 ≈ 0.67 rad/s，即小车以 0.15 m/s 前进、同时每秒转约 38°，走出一圈直径约 0.45 m 的圆弧。原地旋转时 vR = −vL，v = 0，ω = 2vR/L——全部速度变成了旋转。

### 4.2 PWM 调速：数字输出怎么控制模拟量

单片机的引脚只有两种状态：高电平和低电平，没法直接输出"一半的电压"。脉冲宽度调制（PWM，Pulse Width Modulation）绕开这个限制：让引脚高速地在高低之间切换，切换得足够快时，电机"感受"到的是平均值。指导书 2.2.2 给出三个要点：

- 占空比 = 高电平时间 / 周期 × 100%；
- 电机平均电压 = 电源电压 × 占空比；
- PWM 频率一般选择 10kHz–20kHz，避免人耳可闻噪声。

举例：11.1V 电池、占空比 50%，电机绕组上的平均电压约 5.55V——转速随之下降。这就是后面所有实验里"改 push_val 就改速度"的原理。

指导书注意：第二章说 PWM 频率一般选 10kHz–20kHz，而本书全部实验代码用的是"定时器中断 + 软件计数"产生的约 50Hz PWM（周期 20ms，分 20 级或 200 级）。这是教学代码的简化：50Hz 低频下电机可能有轻微的抖动或电流声，属于正常现象，不影响实验结论；两处口径不同不是矛盾，而是"教材讲理想、代码讲可读"。

指导书 2.2 节还介绍了 STC12C5A60S2 内置的两个可编程计数器阵列（PCA）模块，可以工作于 8 位 PWM 模式（相关寄存器 CCON/CMOD/CCAPM0/CCAPM1/CL/CH 等，见指导书表 4-1 的 PCA 寄存器表）。实验代码没有走 PCA 硬件 PWM 这条路，但它是进阶改进方向：硬件 PWM 不占 CPU、频率可以做高。

### 4.3 PID：课本上的"标准答案"与代码里的"够用就好"

指导书 2.2.1 给出 PID 控制器三项的分工：

| 控制项 | 作用 | 参数调节原则 |
|---|---|---|
| 比例（P） | 快速响应误差，成比例调节输出 | 增大加快响应，过大会引起振荡 |
| 积分（I） | 消除稳态误差，提高控制精度 | 增大加快消除静差，过大会引起超调 |
| 微分（D） | 预测误差变化趋势，抑制振荡 | 增大增强阻尼，过大会放大噪声 |

放在小车上理解：假设目标是让车巡线居中，"误差"就是车偏离黑线中心的距离。P 项像弹簧——偏得越多，往回打的力度越大，但只有 P 时车总在中心两侧小幅摆动（比例那个"过大会振荡"说的就是它）；I 项记账——如果车因为某侧轮子偏软总是偏左 1cm，I 项把这笔"每天都要偏"的稳态误差累积起来补掉，但记性太好会冲过头（超调）；D 项像阻尼——看到误差正在快速收窄就提前松劲，抑制冲过头，但地面颠簸的噪声也会被它放大。

要说清楚的是：本课程 11 个实验的代码都不是 PID，而是"开关式"控制——传感器状态决定了就直接调用固定速度、固定延时的动作函数（实验九巡线里 spin_right(12,12) 加 delay(80) 是典型的开关式纠正）。PID 出现在第二章，是给"进阶功能"（指导书实验九创新点里写的自适应速度、路径记忆）和实验报告的"算法改进"留的抓手：把巡线的偏移量做成连续误差，用 P/I/D 三个系数替代"见线就猛打方向"，巡线速度和稳定性就能同时上去。

### 4.4 传感器：两类"眼睛"

红外传感器（指导书 2.3.1）：一对红外发射管与接收管。发射管发出一定频率的红外线，前方有障碍物时红外线被反射回来，被接收管检测到；没有障碍物时红外线一路扩散、衰减，接收管收不到。特点：成本低、响应快、易受环境光干扰；应用：近距离避障、黑线检测。本车的三种红外用法本质是同一件事的不同对象：避障（探测障碍物反射）、巡线（黑线吸收红外、白底反射红外）、跟随（探测跟随者身体反射）。每块板上的蓝色电位器用来调反射判定的阈值距离/灵敏度，实验六/八/九都会先调它。

超声波传感器（指导书 2.3.2）：通过测量声波飞行时间计算距离。测距公式：距离 = 声速 × 飞行时间 / 2——除以 2 是因为声波走了一个来回，除 2 才是单程距离。测量范围 2cm–400cm（实验十正文写 SR04 为 3–500cm，以所用模块手册为准），特点：测距远、精度中等、受角度影响大。"受角度影响大"的含义：超声波探头发出的声束有张角，遇到斜面会把回波反射到别处，导致测不到或测得偏大，这是实验十/十一排错时的常见根源。

## 5 第三章设备与环境搭建的补充解读

### 5.1 组装顺序

指导书 3.3.1 给的四步是：将电机固定在底盘电机安装孔位；将轮胎安装到电机输出轴；安装舵机、灯光模块以及各种传感器模块；使用铜柱固定核心控制板。两点补充（补充说明，来自扩展板产品图）：电池盒先固定在底盘下部居中位置、走线经绿色端子接入，再装上层板，避免最后被挡住；传感器小板（巡线/避障）装在车头底盘前缘、探头朝前下方或正前方，装反了后面怎么调电位器都白搭。

### 5.2 开发环境安装与验证

安装（指导书 3.2.1）：Keil uVision IDE 可从官网 https://www.keil.com/ 下载，也可以安装配套资料中提供的 Keil C51 V9.00；配置串口驱动 CH340；把配套资料提供的头文件 STC12C5A60S2.H 拷贝到 Keil 软件安装目录（例如 C:\Program Files\Keil\C51\INC）。头文件这一步不能省——它是 STC12 特有寄存器（P4、P4SW、AUXR 等）的名字与地址对照表，缺了它编译器不认识 sbit LED_R = P4^6 这类写法。

验证（指导书 3.2.2）：用 USB 电缆把开发板连到电脑，打开设备管理器（"我的电脑"右击→属性→设备管理器），在"端口"里看是否出现 usb-serial ch340 字样（界面截图显示为 USB-SERIAL CH340 (COM4) 或类似条目，图上红色标注："出现 ch340 表示已经安装成功"、"没有这个需要重新安装驱动"）；然后打开串口监视器验证串口通信正常。

指导书注意：指导书 3.2.1 写"Keil uVision IDE"，预备实验写"Keil uVision2 IDE"，配图里 µVision2 与 µVision3 的界面都有。版本差异不影响任何操作流程，菜单名一致，按截图找按钮即可。

## 6 预备实验手把手

预备实验的官方目的有两条：掌握轮式机器人用 C51 开发板与计算机硬件连接及其基本结构；熟悉及掌握 Keil uVision IDE、ISP 下载软件及串口调试终端的使用方法。设备与软件：轮式机器人套件、ISP 下载线和串行接口线（共用）、计算机、电源；Keil uVision2 IDE、程序下载软件、串口调试软件。以下按指导书"三、实验内容和步骤"的顺序展开，界面细节来自指导书截图的逐项描述。

### 6.1 第一步：接线

三条线（指导书原话）：连接单片机扩展板 ISP 接口（Micro USB 接口）到计算机，以便程序下载；连接单片机扩展板串行接口（Micro USB 接口）到计算机，以便调试和交互；连接机器人到电池或者供电电源。注意 ISP 口和串口是两个 Micro USB 口，别插混；电池最后接。

### 6.2 第二步：Keil 建工程到编译出 .hex

预备实验把这一步拆成 ①②③④ 四小步，对应指导书 img_009–img_018 的截图：

① 建用户文件夹、拷头文件。新建一个文件夹放工程，把"所需头文件"文件夹中的 STC12C5A60S2.H 拷贝到 C:\Program Files\Keil\C51\INC 文件夹里。工程、源文件、输出都放在这个文件夹里，方便管理。

② 新建项目工程。进入 Keil uVision2 IDE：Project→New Project（截图显示 Project 菜单第一项 New Project... 被红圈圈出），命名并保存在刚建的用户文件夹内（保存类型 *.uv2）。随后弹出"Select Device for Target 'Target 1'"对话框，选择单片机生产公司及类型：Atmel、AT89S52（截图显示 Vendor: Atmel、Device: AT89S52 蓝色选中）。会弹出问句"Copy Standard 8051 Startup Code to Project Folder and Add File to Project?"，按指导书流程选"否"即可（指导书未强调，选"是"也能编译）。

指导书注意：车上实际芯片是 STC12C5A60S2，为什么 Keil 里选 Atmel AT89S52？因为 Keil 的通用 51 器件库里就用 AT89S52 这类标准 8051 内核做编译目标，寄存器定义靠我们拷进去的 STC12C5A60S2.H 补齐；这是 51 系列开发的通行做法，不影响生成的机器码在 STC12 上运行。

③ 新建 C 程序文件并加入工程。File→New 新建文件，编辑好程序后保存为 *.c 文件（指导书示例名为 HelloRoBot.c；提醒原话："注意程序关键字的拼写、英文标点、字母的大小写等"）。然后在工程窗口右键单击 Source Group 1→Add Files to Group 'Source Group 1'（截图红圈圈出），把 .c 文件加进去；加好后 Source Group 1 前出现 + 号，单击 C 文件，Keil 会自动识别关键字并以不同颜色提示，有利于少犯错误。

④ 生成 .hex 并编译。Target 1 右键单击→Option for target 'Target 1'→Output 标签页→勾选"Create HEX Fi:"（截图显示 HEX 下拉为 HEX-80）→确定。然后点击工具栏的编译按钮（Build target，快捷键 F7），Keil 对工程里的 C 源文件编译链接。指导书给出成功输出的截图，内容为：

```text
Build target 'Target 1'
compiling HelloRoBot.c...
linking...
Program Size: data=58.3 xdata=0 code=1246
creating hex file from "HelloRoBot"...
"HelloRoBot" - 0 Error(s), 0 Warning(s).
```

判断标准：编译要求没有 Error，允许 Warning。生成的可执行文件 HelloRoBot.Hex 存放在 C 源程序所在目录。注意"Create HEX Fi:"不勾的话，链接再成功也不会生成 .hex，STC-ISP 里将无文件可打开——这是新手最常踩的第一坑。

### 6.3 第三步：STC-ISP 烧录

烧录前先做两件事。第一，看芯片型号：V51 开发板上的芯片型号通过芯片上的丝印区分，指导书原话提示"打上手电筒照射，开发板稍微倾斜一点，丝印会看得更清晰些"（截图展示的示例芯片丝印为 STC 89C52，红框圈出）。第二，确认驱动与串口号：micro USB 数据线连接单片机和电脑后，在设备管理器→端口里找 USB-SERIAL CH340 (COMx)，记住括号里的 COM 号。

{{IMG:img_020.png|芯片丝印示例：STC 89C52（烧录选型以板上丝印为准）}}

STC-ISP 的操作序列（对应 img_021–img_024）：

1. 打开烧录软件 stc-isp-15xx-v6.85，在"单片机型号"下拉框选型号。指导书以 STC89C52 为例：在"STC89C51 系列"里找到 STC89C52。
2. 在"串口号"下拉框里选中刚才记下的 USB-SERIAL CH340 (COMx)。
3. 点"打开程序文件"，选择后缀为 .hex 的程序文件（截图红字标注"打开 .hex 后缀的文件"）。
4. 烧录时序（指导书原话）："插上 usb 后，没有灯亮，然后点击烧录软件的'下载/编程'，L1 亮了，这时立刻按下板子的电源开关，然后 L2 亮了，这样就开始烧录了。"这个"先点下载、再上电"的顺序是 STC 冷启动下载机制决定的：单片机只有在检测到上电瞬间的下载信号才进入编程状态，已经跑着程序的板子不会响应。烧录成功时界面显示"单片机型号/固件版本号/操作成功!"并有"烧录成功!"字样（img_024）。

两条硬性警告（指导书原话，感叹号是原文的）：上传程序的时候不能占用 RX、TX 串口，比如蓝牙模块、WiFi 模块都需要取下来，否则会烧录失败；配合 3.3 节扩展板说明的"烧录开关：烧录程序时拨 ON"。烧录失败时按这两条逐项检查，再检查 COM 号与型号选择。

指导书注意：烧录软件标题为 stc-isp-15xx-v6.85，指导书选型示例用 STC89C52，而小车上实际使用的是 STC12C5A60S2（指导书在括号里自己注明了）。STC12C5A60S2 在列表的"STC12 系列"里也能找到；两个型号都能选的规律是——以板上丝印为准，选错型号最典型的症状是"一直等待单片机响应"或烧进去行为异常。

### 6.4 第四步：串口调试助手看结果

程序从下载那一刻就开始运行。查看输出：先用串口线把单片机串口与计算机 USB 口相连，在设备管理器确认要使用的串口号（img_025 的树形截图显示 USB-SERIAL CH340 (COM5)），没有的话重装 CH340 驱动；打开串口调试助手（截图为 CM 精装版 V3.8.3），左侧串口设置依次为串口号、波特率 9600、校验位 NONE、数据位 8、停止位 1，点圆形"打开"按钮；右侧"串口数据接收"区开始滚动单片机发来的数据。若显示的是乱码般的十六进制数值，把接收区设置的"十六进制显示"勾选状态切换一下再看。工具栏的"Reset"按钮可让下载到单片机内的程序重新运行一次（指导书原话）。

### 6.5 收尾

指导书预备实验第 4 步：做完实验断开电源，将开关拨到关闭档（OFF），系统在不使用时没有消耗电能，电池可以用得更久；拆卸串口线还原。

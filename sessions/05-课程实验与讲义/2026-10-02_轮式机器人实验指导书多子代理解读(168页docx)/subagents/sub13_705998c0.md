void key_scan(void)
{
    while (key!=0);       //当按键没有被按下一直循环
    while (key==0)        //当按键被按下时
    {

}

Walkthrough with numbered execution order:
- 状态A（松开）：key=1 → 第一个 while 死等。第二个 while 条件不成立…… wait, execution reaches the second while only after the first exits. Order: ① while(key!=0) — 每次循环读 P2.7，为 1 就原地打转（空语句）；按下瞬间 key=0，条件假，往下走。② while(key==0) — 此时必成立（刚检测到 0），进入循环体。③ delay(10) — 跳过前沿抖动（<10ms）。④ if(key==0) — 10ms 后再读；抖动已结束，真按下则仍为 0 → 进入。若这次读到 1（说明刚才只是毛刺）→ 跳过 if，回到 ② 的条件判断：key==0 为假 → 退出整个函数，相当于一次误触发被过滤。⑤ delay(100) — 确认按下后再停留约 100ms（给操作者反应时间/进一步稳定）。⑥ while(key==0); — 死等松开；按住不放程序就停在这里。松开瞬间 key=1 → 退出。⑦ 回到 ② 条件：key==0 不成立（已松开）→ 退出函数。

* Function       rimer0
* @author        Danny
* @date          2017.08.16
* @brief         TIMER0中断服务子函数产生PWM信号，

* @param[out]    void

void timer0() interrupt 1 using 2
